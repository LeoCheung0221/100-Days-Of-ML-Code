# 100 天，每天一个能跑完的实验

给已经会写程序的人。不是零基础课程，也不是「100 天学会机器学习」的证书。

每天只做一件事：跑一小段代码，然后用一句话讲清它错在哪。100 天结束时，你应能把一个小模型的失败讲给另一个工程师听。

2019 年的概念问答和论文笔记留在 [`archive/2019`](archive/2019)。

## 怎么看一天

每天一个目录，里面有说明和一份能直接运行的程序。说明只回答三件事：今天在比什么、程序印出了什么、你要能讲出的那一句。

需要 Python 3.8 或更高。

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python days/01-line-that-misses/fit_line.py
```

| 86–100 | 把这个模型讲给另一个工程师 | 未写 |
