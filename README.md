## 第 1 天 · 样本内残差

查询点 `x = 4` 在训练集内。最近邻检索到收盘 **20.0**，残差 **0**。普通最小二乘在仿射类中最小化残差平方和，拟合值 **11.79**，残差 **8.2**。零残差是查表。8.2 是直线这个模型类付不出零残差的部分。

| 日 | 收盘 y | OLS 拟合值 |
|---|---:|---:|
| 1 | 2.1 | 1.98 |
| 2 | 3.9 | 5.25 |
| 3 | 6.2 | 8.52 |
| **4** | **20.0** | **11.79** |
| 5 | 10.4 | 15.06 |

| 估计器 | 在 x = 4 的输出 | 输出 | 样本内残差 |
|---|---|---:|---:|
| 最近邻 | 查询点与训练点重合，输出标签 | 20.0 | 0 |
| OLS | `ŷ = 3.27x − 1.29` | 11.79 | 8.2 |

> 参数化均值不是训练标签的检索。查询点落在训练支撑上时，最近邻残差为零。直线的残差是模型类的近似误差。

[完整讲解](docs/season-01/day-01.md) · [代码](days/01-line-that-misses) · [这一季的一百天](docs/season-01)

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python days/01-line-that-misses/fit_line.py
```

同一组数字的画面在 [`site`](site)。进入该目录后执行 `npm install`，再执行 `npm run dev`。

## 🧭 一天的形状

| | 留下什么 |
|---|---|
| **比** | 两种做法，面对同一组行情 |
| **跑** | 一个文件，印出误差 |
| **讲** | 一句话，说明失手从哪来 |

不下单。行情先用历史收盘价。接到 LAT 的回测时，仍按这三步写。

难度只加一条新约束：前一天还能用的偷懒办法，下一天收走一个。
