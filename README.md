# 观测席

**一天一个实战。一百天一季。难度只升不降。**

会写程序的人从这里开始。每天跑一段代码，留下一句能讲给别人的话：模型在这组价格上，错在哪。

旧的概念问答在 [`archive/2019`](archive/2019)。系列目录在 [`docs`](docs)。

## ✦ 第 1 天已经能看

五个交易日。第四天被拉到 **20**，其余四天大致沿一条线。

| 日 | 收盘 | 直线说出 |
|---|---:|---:|
| 1 | 2.1 | 1.98 |
| 2 | 3.9 | 5.25 |
| 3 | 6.2 | 8.52 |
| **4** | **20.0** | **11.79** |
| 5 | 10.4 | 15.06 |

| 做法 | 它怎么回答第四天 | 说出 | 误差 |
|---|---|---:|---:|
| 死记 | 抄最近的那个收盘价 | 20.0 | 0 |
| 直线 | 五天一起拟合，再读第四天 | 11.79 | 8.2 |

直线是 `y = 3.27x − 1.29`。它要照顾另外四天，所以到不了 20。**8.2** 就是这条航线的代价。

> 直线不是把见过的价格存起来。它选了一条航线，离线的那一天一定被说错。

[完整讲解](docs/season-01/day-01.md) · [代码](days/01-line-that-misses) · [这一季的一百天](docs/season-01)

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python days/01-line-that-misses/fit_line.py
```

同一组数字的画面在 [`site`](site)。进入该目录后执行 `npm install`，再执行 `npm run dev`。

## ▣ 一天的形状

| | 留下什么 |
|---|---|
| **比** | 两种做法，面对同一组行情 |
| **跑** | 一个文件，印出误差 |
| **讲** | 一句话，说明失手从哪来 |

不下单。行情先用历史收盘价。接到 LAT 的回测时，仍按这三步写。

难度只加一条新约束：前一天还能用的偷懒办法，下一天收走一个。
