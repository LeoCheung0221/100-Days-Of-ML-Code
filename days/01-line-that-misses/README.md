# 第 1 天 · 样本内最近邻与普通最小二乘

查询点 `x = 4` 位于训练集内。比较最近邻与普通最小二乘在该点的样本内残差。

最近邻与训练横坐标重合，输出标签 **20.0**，残差 **0**。OLS 在仿射类中最小化残差平方和，得到 `ŷ = 3.27x − 1.29`，在 `x = 4` 的拟合值为 **11.79**，残差 **8.2**。零残差是检索。8.2 是模型类的近似误差。

| t | 收盘 y | 拟合值 ŷ | 残差 |
|---:|---:|---:|---:|
| 1 | 2.1 | 1.98 | 0.12 |
| 2 | 3.9 | 5.25 | −1.35 |
| 3 | 6.2 | 8.52 | −2.32 |
| **4** | **20.0** | **11.79** | **8.21** |
| 5 | 10.4 | 15.06 | −4.66 |
