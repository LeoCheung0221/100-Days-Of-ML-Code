# ✦ 第 1 天 · 直线会放过拉高的那一天

五个交易日。第四天收盘 **20**，其余四天大致沿一条线。

## 比

| 做法 | 它怎么回答第四天 |
|---|---|
| 死记 | 抄最近的那个收盘价 |
| 直线 | 五天一起拟合，再读第四天 |

## 跑

在仓库根目录：

```bash
pip install -r requirements.txt
python days/01-line-that-misses/fit_line.py
```

| 做法 | 说出 | 误差 |
|---|---:|---:|
| 死记 | 20.0 | 0 |
| 直线 | 11.79 | 8.2 |

同一组数字的画面在 [`site`](../../site)。

## 讲

> 直线不是把见过的价格存起来。它选了一条航线，离线的那一天一定被说错。
