# 第 1 天：记住样本，和画出一条会失手的线

## 今天在比什么

五个交易日的收盘价。第四天被拉到 20，其余四天大致沿着一条线。两种做法都要回答第四天：

- 死记：在这五个点里找 x 最接近的一个，用它的收盘价当作答案。
- 画线：用这五个点拟合一条直线，用这条线回答同一天。

浏览器里的同一课在仓库 [`site`](../../site)。打开后不用读代码，能看见直线从 20 下面穿过去。

- 死记会把抬高的 y 原样背出来，误差是 0。
- 直线要照顾其他点，会把这个点拉回线附近，所以一定说错。

## 运行

在仓库根目录：

```bash
pip install -r requirements.txt
python days/01-line-that-misses/fit_line.py
```

## 你要能讲出的一句

模型不是把见过的点存起来。它选了一条线，离线的点就会被说错。这是用一条线换来的代价。
