# 第 1 天：记住样本，和画出一条会失手的线

## 今天在比什么

两种做法面对同一个新点：

- 死记：在训练点里找 x 最接近的一个，用它的 y 当作答案。
- 画线：用训练点拟合一条直线，用这条线回答新的 x。

训练点里有四个大致在一条线上，x=4 的那个点被故意抬高。问的还是 x=4：

- 死记会把抬高的 y 原样背出来，误差是 0。
- 直线要照顾其他点，会把这个点拉回线附近，所以一定说错。

## 运行

在仓库根目录：

```bash
pip install -r requirements.txt
python days/01-line-that-misses/fit_line.py
```

## 你要能讲出的一句

模型不是把见过的点存起来。它选了一条线，离线的点就会被说错。这是用一条线换来的代价。
