# 🛰️ 第 1 天 · 直线会放过拉高的那一天

✨ 观测席开机的第一课 · 🟢 可跑 · 📉 不下单

五盏灯悬在交易日的天上。四盏顺着安静的航线往前走，第四盏被一把拉到 **20**。领航员有两个习惯，必须当着你的面回答：那一盏现在在哪。

🧠 **死记**把亮光塞进口袋，说出 **20.0**，误差 **0**。它像天才，因为它看见了答案。  
📐 **直线**画出 `y = 3.27x − 1.29`，说出 **11.79**，失手 **8.2**。它要照顾另外四天，所以不肯为了一盏灯改道。

| 🗓️ | 💰 收盘 | 📐 直线 |
|---|---:|---:|
| 1 | 2.1 | 1.98 |
| 2 | 3.9 | 5.25 |
| 3 | 6.2 | 8.52 |
| 🔥 **4** | **20.0** | **11.79** |
| 5 | 10.4 | 15.06 |

🔥 金点停在天顶，蓝色航线从脚下穿过。`20.0 − 11.79 = 8.21`，印出来是 **8.2**。这一竖不是故障，是航线的票价。

> ✨ 直线不是把见过的价格存起来。它选了一条航线，离线的那一天一定被说错。

🎬 想先看那一竖落下来，打开 [`site`](../../site)，`npm install` 之后 `npm run dev`。点会一颗颗亮，第四天标成异常拉高，直线穿过去，虚线写下失手 8.2。播完可以再看一次。

🐍 想让终端把同一组数字印出来，在仓库根目录：

```bash
python3 -m venv .venv

pip install -r requirements.txt
python days/01-line-that-misses/fit_line.py
```
