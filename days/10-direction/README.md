同一条直线 `ŷ = 3.27x − 1.29`。拟合的一步差分恒为 **3.27**。四步方向命中 **3/4**。

第四日绝对残差 **8.21**，方向命中。第五日绝对残差 **4.66**，方向不中。价格损失更小的那一天，符号是错的。
