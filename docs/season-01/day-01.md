# ✦ 第 1 天 · 直线会放过拉高的那一天

[第 1 季](README.md) · 模型 · 可跑

五个交易日的收盘价。第四天被拉到 20，其余四天大致沿一条线。今天只比两种做法，都要回答第四天。

| 日 | 收盘 | 直线 |
|---|---:|---:|
| 1 | 2.1 | 1.98 |
| 2 | 3.9 | 5.25 |
| 3 | 6.2 | 8.52 |
| **4** | **20.0** | **11.79** |
| 5 | 10.4 | 15.06 |

---

## 比

领航员有两个习惯。

**死记**在这五个点里找日期最接近的一个，把它的收盘价原样说出来。问的就是第四天，所以它说出 20，误差是 0。它赢了这一天，是因为它把这一天存了起来。

**直线**用五个点一起拟合 `y = 3.27x − 1.29`，再把 x = 4 代回去，说出 11.79。这条线是最小二乘：它把五个点到线的距离平方加起来，选让这个和最小的斜率和截距。第四天若要把整条线抬到 20，另外四天会离得更远，平方和会更大。所以线从 20 下面穿过去。

| 做法 | 说出 | 误差 |
|---|---:|---:|
| 死记 | 20.0 | 0 |
| 直线 | 11.79 | 8.2 |

8.2 不是计算误差。20.0 − 11.79 = 8.21，印出来是 8.2。它是「用一条线照顾五天」换来的代价。

今天问的第四天就在这五个点里面。死记误差为 0，是因为题目允许它看见答案。第 6 天才会问一个训练里没有的日子。第 7 天才会把第五天藏起来当考试。

---

## 跑

在仓库根目录：

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python days/01-line-that-misses/fit_line.py
```

需要 Python 3.8 或更高。脚本印出的直线、11.79 和 8.2 应与上表一致。代码在 [`days/01-line-that-misses`](../../days/01-line-that-misses)。

同一组数字的画面在 [`site`](../../site)。进入该目录后执行 `npm install`，再执行 `npm run dev`。第四天的点停在 20，直线从下面穿过，中间那一竖标着失手 8.2。这一页不下单。

---

## 讲

> 直线不是把见过的价格存起来。它选了一条航线，离线的那一天一定被说错。

死记能在见过的那天零误差。换一天、换一个没存过的价格，它只能抄邻居。直线从第一天起就放弃零误差，用来换一条也能回答其他日子的航线。

下一天收走「只交一个误差」。同一个 8.2，要写成绝对误差和平方误差两个数。平方会把第四天放得更重。
