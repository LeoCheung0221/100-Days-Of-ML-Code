# 第 1 天 · 样本内最近邻与普通最小二乘

[第一阶段 · 模型](README.md) · 可运行

今天的学习要点：查询点落在训练集内部时，最近邻残差为 0 只说明标签被检索到了；普通最小二乘的残差 8.2 是仿射函数类的近似误差。

## 费曼法讲解

把五个收盘价想成一张只有五行的表。第一天 2.1，第二天 3.9，第三天 6.2，第四天 20.0，第五天 10.4。有人指着第四天问：这个位置该报多少。第一种答法是把表翻到第四行，照着念 20。这就是最近邻。问的横坐标正好等于某一行的横坐标，邻居就是那一行自己，报出来的数等于标签，残差是 0。这个 0 没有看过另外四天。它只证明一件事：问题的位置已经写在训练表里，答案是把那一格抄出来。

第二种答法不肯抄表。它只允许自己画直线，直线写成「收盘大约等于斜率乘上第几天，再加一个截距」。五个点到这条直线的竖直距离，先平方再相加，要这个和最小。算完是 `ŷ = 3.27x − 1.29`。第四天代入：`3.27 × 4 − 1.29 = 11.79`。20 减 11.79 等于 8.21，脚本把绝对残差印成 8.2。直线没有背下 20。若把整条线抬高，让它穿过 20，另外四天会离得更远，平方和变大，总损失上升。11.79 是五个点之间的妥协，8.2 是第四天为这个妥协留下的距离。

两种答法并排之后，零和 8.2 就不能再被说成「一个准、一个不准」。零来自查表。8.2 来自直线这种形状到不了 20。形状选错了，样本内也会留下残差。形状选成「把最近的一行抄出来」，样本内可以没有残差，但那不是拟合。

## 核心知识

记第 `t` 日收盘为 `y_t`，横坐标 `x_t = t`。查询 `x = 4` 落在训练横坐标 `{1,2,3,4,5}` 的凸包内，而且正好撞上一个训练点。这不是留出，也不是样本外。

最近邻是

```text
î = argmin_i |x_i − x|
ŷ = y_î
```

`x = 4` 时 `î = 4`，`ŷ = 20.0`，残差 `20.0 − 20.0 = 0`。

普通最小二乘的假设类是仿射函数 `ŷ = β₁x + β₀`。设计矩阵每一行是 `[x_i, 1]`。系数是残差平方和的最小值点：

```text
β̂ = argmin_β ||y − Xβ||²
```

五个点上的闭式解由 `numpy.linalg.lstsq` 给出，没有迭代。打印到两位小数是斜率 3.27、截距 −1.29。拟合值依次为 1.98、5.25、8.52、11.79、15.06。残差依次为 0.12、−1.35、−2.32、8.21、−4.66。残差有正有负，直线没有一条「放过某一点」的附加规则。它只是不能把五个残差同时变成零。第四日残差最大，是因为它离开其余四点所支撑的斜率最远。平方损失会把这个大残差抬得更重，那是第 2 天的题目。本日只要求把两种估计器放在同一次查询上。

| 估计器 | 在 x = 4 的输出 | 样本内残差 | 残差的来源 |
|---|---:|---:|---|
| 最近邻 | 20.0 | 0 | 查询点与训练点重合，输出等于标签 |
| OLS | 11.79 | 8.2 | 仿射类里残差平方和的最小解 |

## 拓展领域

量化研究里，这两种答法会以更隐蔽的样子再出现。用「和今天最像的那一天」去报明天，样本内可以很漂亮，因为相似是在已经看见的日子上定义的。线性因子模型则先限定收益只能由少数几个暴露的线性组合解释，拟合不到的部分留在残差里。残差大，不一定是实现写错了。它可能是函数类太窄。残差是零，也不一定是模型有预测能力。它可能是查询点和训练点重合，标签被原样检索。

以后做截面回归、做风格暴露、做「找历史相似行情」，都要先问查询点在不在训练支撑上。在支撑上，最近邻的零误差没有外推含义。直线的非零误差是模型类的近似误差，可以拿来比较不同的函数类，不能拿来宣布样本外有效。实盘下单、费用、涨跌停都不在本日。页面上的动画只把这五个点和这条线画出来，不生成订单。

## 实战总结

仓库根目录：

```bash
python days/01-line-that-misses/fit_line.py
```

脚本应打印 `y = 3.27 x + -1.29`，最近邻残差 `0.0`，直线残差 `8.2`。实现是 [`fit_line.py`](../../days/01-line-that-misses/fit_line.py)。同一组数字画在 [`site`](../../site)，第四日的点在 20，直线过 11.79，竖线标出残差 8.2。

今天交出去的只有这一对比较。查询点属于训练集。最近邻的 0 不能写成「模型有效」。直线的 8.2 不能写成「直线失败、所以不该用直线」。它是仿射类在这五个点上的最小平方残差。第 2 天起，同一个残差要同时交绝对损失和平方损失。第 6 天才会把查询移到训练支撑外面。第 7 天才把第五日留出，并宣布训练残差不再当成绩。
