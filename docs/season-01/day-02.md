# 第 2 天 · 绝对误差与平方误差

[第一阶段 · 模型](README.md) · 可运行

今天的学习要点：同一条直线、同一组残差，必须同时交绝对损失和平方损失。第四日占绝对损失的 0.4928，占平方损失的 0.6997。

## 费曼法讲解

第 1 天留下五个残差：0.12、−1.35、−2.32、8.21、−4.66。如果只说「第四天差了 8.2」，你听到的是一个距离。如果只说「五个点的平方和是 96.339」，你听到的是一个总数。两个说法都漏掉了同一件事：第四天在两种算法里的分量不一样。

把残差的绝对值加起来，得到 16.66。第四天的 8.21 占其中 0.4928，不到一半。把残差先平方再相加，得到 96.339。第四天的平方是 67.4041，占 0.6997，接近七成。同一个点，换一种加法，份额从不到一半变成接近七成。不是第四天突然变得更重要，是平方这个函数在绝对值大于 1 的时候把大误差抬得更高，在绝对值小于 1 的时候把小误差压得更低。第一天的 0.12 平方之后只剩 0.0144，在总数里几乎看不见。

所以今天不允许只交一个误差。只交 8.2，别人不知道这是绝对残差、平方残差，还是某种平均。只交 16.66 或只交 96.339，别人不知道第四天被放大了多少。两个数并排，份额才出现。

把这件事想成两种记账。绝对损失一笔一笔记距离，第四天记 8.21，第五天记 4.66，加总时各算各的。平方损失先把距离变成面积，第四天的面积是 67.4041，第五天是 21.7156，前三天的面积加起来还不到 8。同一本账，两种算法，第四天从「不到一半」变成「接近七成」。以后凡是看见一个误差下降了，先问下降用的是哪一种加法。

与第 1 天的关系：斜率 3.27、截距 −1.29 不变，残差向量不变；今天只是给同一向量配两个范数。与第 3 天的关系：第 3 天把 `L2 = 96.339` 拆成五个 `π_t`，其中第四日 0.6997 与本日平方份额是同一个数。与第 4 天的预告：端点弦在 `L1` 上可以赢直线（12.0000 对 16.6600），在 `L2` 上必输（136.3837 对 96.3390）——换损失，名次可以反转，即使函数类仍是仿射。

误区：用 `L2` 下降宣布「拟合全面变好」，而第四天仍占 0.6997；或只用 `L1` 选模型，忽略平方目标下 OLS 才是类内最优。本日 OLS 系数来自最小化平方和，因此 `L2` 上的 96.339 是定义内的最优值；`L1 = 16.66` 是同一系数下的诊断读数，不是另一个 `β̂`。培训新人时让 TA 手填表五行的 |r| 与 r² 再手算 16.66 与 96.339，比背公式更不易混 L1 与 L2。合计行必须与脚本一致，否则后面份额 0.4928 无从谈起。

## 核心知识

沿用第 1 天的五个收盘和同一条直线 `ŷ = 3.27x − 1.29`。残差 `r = y − ŷ`。两个样本内损失是这个残差向量的两个范数：

```text
L1 = Σ |r_t|
L2 = Σ r_t²
```

| t | y | ŷ | r | \|r\| | r² |
|---:|---:|---:|---:|---:|---:|
| 1 | 2.1 | 1.98 | 0.12 | 0.12 | 0.0144 |
| 2 | 3.9 | 5.25 | −1.35 | 1.35 | 1.8225 |
| 3 | 6.2 | 8.52 | −2.32 | 2.32 | 5.3824 |
| 4 | 20.0 | 11.79 | 8.21 | 8.21 | 67.4041 |
| 5 | 10.4 | 15.06 | −4.66 | 4.66 | 21.7156 |
| 合计 | | | | 16.66 | 96.339 |

第四日占 `L1` 的 0.4928，占 `L2` 的 0.6997。份额取四位小数，是为了和第 3 天的拆分对齐。`|r| > 1` 时平方放大离群点，`|r| < 1` 时平方压低小残差。这是 `x ↦ x²` 的形状，不是叙事上「第四天更关键」的判断。

第 1 天的普通最小二乘最小化的是平方和，不是绝对值和：

```text
β̂_L2 = argmin_β Σ (y_t − β₁ x_t − β₀)²
```

打印出来的斜率 3.27 和截距 −1.29 是这个最小值点。绝对损失的最小值点一般要另外求解，今天不求。今天只要求：已经估出的这条直线，必须同时报出 `L1` 和 `L2`，以及第四日在两者中的份额。损失一旦换掉，最小值点可以换人。那是第 4 天端点弦会碰到的事实，今天先把两个范数摆在同一条线上。

| 读数 | 第 2 天（本日） | 第 3 天 | 第 4 天（端点弦 vs OLS） |
|---|---|---|---|
| 标量损失 | `L1`、`L2` 并排 | RSS 拆份额 | 两线各算 `L1`、`L2` |
| 第四日权重 | 0.4928 / 0.6997 | `π_4 = 0.6997` | 第四日 `\|r\|` 11.6750 vs 8.2100 |
| 是否重估 `β̂` | 否 | 否 | 弦用端点，OLS 仍第 1 天 |

## 拓展领域

收益预测里，均方误差和平均绝对误差经常被当成可以互换的「误差小」。它们优化的不是同一个点。平方损失对少数大残差极敏感，所以一个跳空、一个错价、一次除权没有处理干净，就会主导整个训练。绝对损失对大残差的惩罚是线性的，离群点仍在，但不会以平方的速度吞掉其余日子。

因子回归、波动率目标和组合优化里，目标函数换一个范数，解就可以换。报告「误差」而不写是哪一个范数，读者无法知道离群日被放大了多少。今天的五个点把这件事缩到一张表上：同一个残差向量，`L1` 份额 0.4928，`L2` 份额 0.6997。以后看见均方误差大幅下降，先问下降是不是来自一两个被平方放大的点，而不是来自整段拟合都变好了。

量化工作流陷阱：训练用 MSE，汇报只报 MAE，或反过来；监控 dashboard 混用两种尺度，导致「第四天权重」在会里被争论却拿不出 0.4928 与 0.6997 的对照。稳健回归（Huber、分位数）存在 precisely 因为 `L1` 与 `L2` 的权衡；本季前几周不引入新估计器，但要在语言上把范数写死。

第 5 天删第四日会动斜率，不是因为换了 `L1`，而是因为信息集变了。不要把 0.6997 误读成「删掉就万事大吉」的判决；份额只说明平方和里的重量，删点后的 −1.1729 才是位移读数。

手算巩固：对 `|r| = 8.21`，平方项 67.4041 约为绝对项的 8.2 倍，因此单点就能吃掉近七成 `L2`；对 `|r| = 0.12`，平方项 0.0144 远小于 0.12，故第一日在 `L1` 里占 0.12/16.66 而在 `L2` 里几乎可忽略。这个非线性是范数定义的一部分，不是数据「突然变脏」。若团队讨论「要不要 winsorize 第四天」，应同时展示 winsorize 后 `L1` 与 `L2` 谁下降更多——只报一个范数会掩盖 trade-off。

卡片类比（与第 9 天预告）：五张卡片各写一对 `(t, r_t)`。`L1` 把五张背面绝对值相加得 16.66；`L2` 把背面平方相加得 96.339。洗牌卡片顺序不改变背面数字，故两损失与第 9 天一样对「仅换行序」不变。今天尚未 shuffle，但已固定残差向量——第 3 天再拆 `L2` 的坐标。

与第 9 天：行序打乱不改变本日的 16.66 与 96.339，因为残差向量不变。与第 10 天：方向评分不再看水平残差 8.21，但本日建立的「同一向量、两范数」语言仍用于读水平误差。推导上，`\|r\|_2^2` 与 `\|r\|_1` 在有限维上都是范数，但只有 `L2` 与 OLS 目标一致；把 Lasso 的 `L1` 惩罚与这里的 `L1` 损失混名，是初学者常犯的概念错误——本日 `L1` 仅指残差绝对值之和，不是系数惩罚。

## 实战总结

仓库根目录，依赖仍是 `numpy==1.24.4`：

```bash
python days/02-two-losses/two_losses.py
```

脚本应打印 `L1 = sum |r| = 16.66`、`L2 = sum r^2 = 96.339`、第四日份额 `0.4928` 与 `0.6997`。实现是 [`two_losses.py`](../../days/02-two-losses/two_losses.py)，直线仍由 `numpy.linalg.lstsq` 给出。

两个损失都是样本内的。查询点仍在训练集里，这两个数都不是留出成绩。今天交出去的是同一残差向量的两个范数，以及第四日份额的差异。第 3 天把平方和拆回每一天，不允许只留 `L2` 这一个标量。第 4 天用端点弦和这条直线比，两种损失可以给出相反的名次。

自检清单：是否只报了 96.339 没报 16.66？是否把 0.6997 说成「第四天决定一切」而非「平方损失下的份额」？是否声称 OLS 也最小化 `L1`？复现时对照第 1 天系数再跑本脚本，份额应四位小数一致。工程师应把本表存进 notebook，作为后续删点、窗口、留出讨论的基准残差向量。

derivation 一句：`d/dr |r|` 在 r≠0 为 sign(r)，而 `d/dr r² = 2r`，故大 |r| 在 L2 边际惩罚更大。五维向量上选 β 时 OLS 对 L2 一阶最优；报告 L1 是对固定 β 的二次诊断。会议里若争论「第四天要不要降权」，请回到 0.4928 与 0.6997 两格，而不是只播 8.2 的动画。第 4 天端点弦若改线，16.66 与 96.339 都会变；本日数值是 OLS 专用基准，后续对比请注明是否仍用第 1 天 β̂。
