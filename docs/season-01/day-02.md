# 第 2 天 · 绝对误差与平方误差

[第一阶段 · 模型](README.md) · 可运行

同一条仿射拟合，同一组残差。本日不允许只交一个误差。绝对损失与平方损失是这个残差向量的两个范数，第四日在两者中的份额不同。

第 1 天的普通最小二乘最小化的是平方和，不是绝对值和。损失一旦换掉，最小值点可以换人。

---

## 两个范数

沿用第 1 天的五个收盘，以及同一条直线

```text
ŷ = 3.27x − 1.29
```

残差 `r = y − ŷ`。两个样本内损失是

```text
L1 = Σ |r_t|
L2 = Σ r_t²
```

| t | y | ŷ | r | \|r\| | r² |
|---:|---:|---:|---:|---:|---:|
| 1 | 2.1 | 1.98 | 0.12 | 0.12 | 0.0144 |
| 2 | 3.9 | 5.25 | −1.35 | 1.35 | 1.8225 |
| 3 | 6.2 | 8.52 | −2.32 | 2.32 | 5.3824 |
| **4** | **20.0** | **11.79** | **8.21** | **8.21** | **67.4041** |
| 5 | 10.4 | 15.06 | −4.66 | 4.66 | 21.7156 |
| 合计 | | | | **16.66** | **96.339** |

第四日占 `L1` 的 **0.4928**，占 `L2` 的 **0.6997**。绝对值里它不到一半；平方之后它接近七成。`|r| > 1` 时平方把离群点放大，`|r| < 1` 时平方把小残差压低。第一日的绝对残差 0.12 进入平方和之后只剩 0.0144。

这不是第四日在叙事上更重要。这是 `x ↦ x²` 的形状。

---

## argmin 跟着损失走

```text
β̂_L2 = argmin_β Σ (y_t − β₁ x_t − β₀)²
```

第 1 天打印的斜率与截距是这个最小值点，不是 `L1` 的最小值点。绝对损失的最小值点一般要单独求解，本日不求。本日只要求：同一条已经估出的直线，必须同时报出两个数。

只报 8.2，读者不知道这是绝对残差、平方残差，还是某种平均。只报 16.66 或只报 96.339，读者不知道第四日被放大了多少。两个数并排，份额才看得见。

## 复现

依赖与第 1 天相同，`numpy==1.24.4`。仓库根目录：

```bash
python days/02-two-losses/two_losses.py
```

脚本应打印 `L1 = sum |r| = 16.66`、`L2 = sum r^2 = 96.339`、第四日份额 `0.4928` 与 `0.6997`。实现是 [`two_losses.py`](../../days/02-two-losses/two_losses.py)，直线仍由 `numpy.linalg.lstsq` 给出。
