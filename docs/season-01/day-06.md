# 第 6 天 · 训练支撑外的查询

[第一阶段 · 模型](README.md) · 可运行

训练横坐标是 `{1, 2, 3, 4, 5}`，支撑为闭区间 `[1, 5]`。本日的查询是 `x = 6`。样本里没有第六日的收盘。没有标签，就没有残差。

两个估计器仍然各给出一个数。最近邻只能复制已见标签。普通最小二乘把仿射函数用到支撑外面，那是外推。两个数之差是估计之间的差距，不是失手。

---

## 支撑

一个查询落在训练支撑内，是指它落在训练横坐标的凸包里。`x = 4` 在凸包内，所以第 1 天的最近邻可以撞上训练点本身，残差可以是 0。`x = 6` 在凸包之外。最近的训练横坐标是 `5`，不是 `6`。

```text
î = argmin_i |x_i − 6| = 5
ŷ_NN = y_5 = 10.4
```

这个 10.4 没有使用 `x = 6` 处的任何新观测。估计器在支撑外没有局部标签，输出退回到边界上最近的已见收盘。

OLS 仍是第 1 天的系数。代入支撑之外：

```text
ŷ(6) = 3.27 × 6 − 1.29 = 18.33
```

| | 输出 |
|---|---:|
| 最近邻 | 10.4 |
| OLS | 18.33 |
| 两者之差 | 7.93 |

7.93 的两边都是估计。任何一边都不是 `y_6`。把 18.33 叫作残差，或把 10.4 叫作对第六日的命中，都是把未观测的标签换成了另一个估计。

---

## 外推使用的是类，不是新数据

仿射类在整个实数轴上有定义，所以代入 `x = 6` 在算术上合法。合法不等于有评分。评分需要 `y_6 − ŷ(6)`。`y_6` 不在样本里，这个差无定义。

直线在支撑外的斜率仍是 3.27。它不会因为离开了最后一个训练点就改用最近邻的规则，也不会把外推值夹回已见收盘的范围。10.4 到 20.0 是训练标签的范围。18.33 落在这个范围里，只是这五个数和这个斜率的结果，不是估计器承诺的边界。

最近邻在支撑外则没有任何斜率。它的输出对一切 `x > 5` 都是 10.4，直到出现一个更近的训练点。本日没有这样的点。
