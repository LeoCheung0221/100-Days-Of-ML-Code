# 第 6 天 · 训练支撑外的查询

[第一阶段 · 模型](README.md) · 可运行

今天的学习要点：查询 `x = 6` 落在训练支撑 `[1, 5]` 外面。最近邻复制第五日的 10.4，直线外推到 18.33，两者相差 7.93。没有第六日的收盘，残差没有定义。

## 费曼法讲解

前五天的问题都问在表里面。今天把问题挪到第六天。表上没有第六天的收盘。两种答法仍然各给一个数，但这两个数都不能拿去和「真值」相减，因为真值不在样本里。

最近邻只能在已经见过的横坐标里找最近的一行。离 6 最近的是 5，那一行的收盘是 10.4。于是它报 10.4。这个数没有使用 `x = 6` 处的任何新观测。支撑外面没有局部标签，输出退回到边界上最近的已见收盘。对一切大于 5 的查询，只要没有更近的训练点，它都会报 10.4。

直线不肯停在边界上。第 1 天的系数代进去：`3.27 × 6 − 1.29 = 18.33`。仿射函数在整条实数轴上都有定义，所以这个代入在算术上合法。合法不等于有评分。评分需要 `y_6 − ŷ(6)`。`y_6` 不存在，这个差无定义。18.33 和 10.4 相差 7.93。7.93 的两边都是估计。把 18.33 叫作残差，或把 10.4 叫作对第六日的命中，都是把没看见的标签换成了另一个估计。也没有第三个数可以充当「折中的真值」。两个估计的平均是 14.365，它仍然是估计的函数，不是第六日的收盘。今天的输出到 10.4、18.33 和 7.93 为止，再加一句残差无定义。三个数都要留下，少一个就会把估计之差误读成对标签的误差。

与第 1 天：第 1 天 `x = 4` 在支撑内且有标签，可算残差 0 与 8.2。本日无标签。与第 7 天：第 7 天 `x = 5` 有标签 10.4 但不进拟合，可算留出残差 −9.6 与 −11.65。本日连标签都没有。与第 5 天：`x = 4` 删点后的内插位移 ≠ 外推；本日 `x = 6` 在 `{1,…,5}` 凸包外。

把支撑想成闭区间 `[1,5]`：训练横坐标的最小凸包。查询 6 在右端外面。最近邻是「卡在右边界」的阶梯延续；OLS 是斜率 3.27 的射线继续向右。7.93 是两种外推规则之差，不是 forecast error。若产品 UI 只展示 18.33 一条线，须在脚注写「无真值、无残差」，否则用户会以为 18.33 是「预测误差为零」附近的数。

## 核心知识

训练横坐标是 `{1, 2, 3, 4, 5}`，支撑是闭区间 `[1, 5]`。查询落在训练支撑内，是指它落在训练横坐标的凸包里。`x = 4` 在凸包内，所以第 1 天的最近邻可以撞上训练点本身。`x = 6` 在凸包之外。

```text
î = argmin_i |x_i − 6| = 5
ŷ_NN = y_5 = 10.4
```

```text
ŷ(6) = 3.27 × 6 − 1.29 = 18.33
```

| | 输出 |
|---|---:|
| 最近邻 | 10.4 |
| 普通最小二乘 | 18.33 |
| 两者之差 | 7.93 |

直线在支撑外的斜率仍是 3.27。它不会因为离开了最后一个训练点就改用最近邻的规则，也不会把外推值夹回已见收盘的范围。训练标签从 10.4 到 20.0。18.33 落在这个范围里，只是这五个数和这个斜率的结果，不是估计器承诺的边界。最近邻在支撑外没有任何斜率。

第 5 天的 `x = 4` 仍在剩余点 `{1, 2, 3, 5}` 的凸包里，那是内插位置上的影响。今天的查询第一次离开支撑。两个问题不要并成「模型在没见过的地方准不准」。没见过的地方今天连标签都没有，准不准无法计算。

| 日次 | 查询 | 标签用于评分？ | 残差 |
|---|---|---|---|
| 第 1 天 | x = 4 | 是 | 0 / 8.2 |
| 第 5 天 | x = 4（删点上下文） | 是（20.0），但看位移 | 11.7286 不当分 |
| 第 6 天 | x = 6 | 否 | 无定义 |
| 第 7 天 | x = 5 | 是（留出） | −9.6 / −11.65 |

## 拓展领域

时间序列预测里，用历史窗口去报还没到来的下一根 K 线，查询天然在支撑外面。最近邻一类的方法会复制最近的已见状态。线性趋势会把斜率继续画出去。两者都可以给出一个数。在标签到来之前，这两个数的差只是估计之间的差距，不是误差。

把外推值说成残差，常见的做法是事后补一个收盘，再倒过来说模型当时差了多少。那样做已经离开了「查询时信息集里没有标签」这个条件。今天故意不构造一个假的第六日收盘。构造它，会把外推问题偷偷换回样本内评分。已见价格的最小值和最大值也不是外推的合法边界。18.33 碰巧落在 10.4 和 20.0 之间，不能据此说直线没有离开已见范围。范围是标签的范围，不是函数的定义域。

工程陷阱：回测脚本在 `t+1` 用当日已知 close 算「预测误差」，却称是 out-of-sample。应先划信息集：预测时刻可看见什么。Live 交易里 7.93 的差意味着两种规则下单不同，但在标签到达前不能评谁对谁错。第 8 天滚动窗口改变的是估计用的日子，不解决本日「无 y_6」的评分空缺。

第 10 天起重写评分对象（方向）；本日仍用水平读数，且明确无残差。不要把 18.33 与第 7 天 22.05 混比——后者是留出点上的有标签比较。

外推语义：NN 在 x>5 上是常数函数 10.4，导数为零；OLS 在全域斜率 3.27。对上涨序列的外推，NN 保守、OLS 激进——7.93 是两种保守/激进规则之差，与谁「更对」无关。若第六日真收盘事后揭晓，那时才可算一次留出式误差；本课故意 withholding y_6 是为了固定信息集。数据管道里「future row with NaN label」应标记为 unscored，而不是填 0 或填 NN 预测再去算 MSE。

闭区间 `[1,5]` 上，训练标签覆盖 2.1 到 20.0，但 x=6 的查询不在训练横坐标集合里。凸包定义保证 x=4 内插、x=6 外推。NN 外推是阶梯函数；OLS 外推是无界仿射——若斜率为负，外推可跌到任意低，本样本斜率 3.27 为正故 18.33 向上。

与第 1 天对比表已列于核心知识。与第 8 天：窗口线只在 `{1,2,3}` 或 `{2,3,4}` 上定义，在 x=6 需另选外推规则（通常用窗口 `β̂` 继续画线），与本日全样本 3.27 不同——换信息集则外推值变。工程师 checklist：off-support 分支是否打印「residual undefined」？是否禁止用 7.93 进 Sharpe？是否区分 estimate gap vs forecast error？off_support.py 四行输出 10.4、18.33、7.93 与 residual undefined 是验收标准，缺一即未达本日要点。

## 实战总结

```bash
python days/06-off-support/off_support.py
```

脚本应打印最近邻 `10.4`、外推值 `18.33`、差距 `7.93`，以及 `residual is undefined`。实现是 [`off_support.py`](../../days/06-off-support/off_support.py)。

今天交出去的是两个估计和一句「残差无定义」。不要把 7.93 写成失手。第 7 天才有一个不参与拟合的标签：第五日被留出，训练残差不再作为成绩。复现时依赖 numpy==1.24.4 与第 1 天相同；18.33 来自 3.27×6−1.29 的打印规则，勿用更高精度系数手算后声称脚本错。本日无 holdout、无 RSS 成绩，只有两估计与差 7.93。与第 1 天同日查询制度不同，勿混读。

自检清单：是否构造假 y_6？是否把 7.93 叫 RMSE？是否说 18.33「在训练范围内所以合理」？复现必须看到 `residual is undefined` 字符串。阅读顺序：第 1 天（in-sample）→ 本日（off-support）→ 第 7 天（holdout with label），分清三种查询制度。

数值锚点复述：NN 10.4、OLS 18.33、差 7.93、残差无定义——四行缺一行都会误导 PM。14.365 平均不是第六日真相，仅作「两估计中点」心算，禁止进报表当 forecast。第 8 天窗口线在 x=6 未定义于本脚本，外推需另指定；本日只用全样本 3.27 线。

量化 workflow：feature store 若在 as-of 时间戳后写入 label，会把本日误改成 in-sample；应用 as-of 截断，使查询时刻看不见 y_6。

费曼再述：问第六日收盘多少，像问表外一格——NN 举「最后一行 10.4」当答案，OLS 用尺子按 3.27 斜率延长到 18.33。没有第六行真值，就不能说谁错谁对。7.93 是两答案之差，不是考题扣分。第 7 天把第五行真值请回考场但不许进复习资料，那是另一种制度。
