# 第 12 天 · 阈值

[第一阶段 · 模型](README.md) · 可运行

今天的学习要点：四步收益 0.8571、0.5897、2.2258、−0.4800 在阈值 0.70 上得到标签 1 0 1 0，同一条永远猜涨的准确率是 0.50，而它在第 11 天的符号标签上是 0.75，这条切分属于标签的定义。

## 费曼法讲解

四个收益按时间写成一行：0.8571、0.5897、2.2258、−0.4800。在高度 0.70 处画一条水平线。0.8571 在线以上，0.5897 在线以下，2.2258 在线以上，−0.4800 在线以下。线以上记 1，线以下记 0，四个标签就是 1 0 1 0。

永远猜涨不读这四个数，它每一步都交 1。对照 1 0 1 0：第一步中，第二步不中，第三步中，第四步不中。四步中两步，准确率 0.50。

把同一条永远猜涨拿到第 11 天的符号标签上。符号只问收益是不是正的。0.8571、0.5897、2.2258 都是正的，−0.4800 是负的，符号标签是 1 1 1 0。永远猜涨对上这四个符号，中三步，准确率 0.75。两次使用的预测完全一样，都是 1 1 1 1。变的是标签。变标签的那一步是第二步：0.5897 大于 0，所以符号把它记成上涨；0.5897 小于 0.70，所以阈值 0.70 把它记成 0。预测没有改口，这一步从命中变成不中，准确率从 0.75 落到 0.50。

0.70 因此写在目标里面，而不是写在评分之后的注释里。它决定 0.5897 进哪一类。把阈值从定义里拿掉，只说「上涨准确率 0.50」，第二步算不算上涨就无法重建。标签的定义里必须带着这条切分。

## 核心知识

简单收益是相邻收盘之差除以前一日收盘。四个数已经给定，阈值也已经给定：

```text
r = 0.8571, 0.5897, 2.2258, −0.4800
τ = 0.70
label = 1{r > 0.70}
```

| 步 | 收益 | 收益 > 0 | 收益 > 0.70 |
|---:|---:|---:|---:|
| 1 | 0.8571 | 1 | 1 |
| 2 | 0.5897 | 1 | 0 |
| 3 | 2.2258 | 1 | 1 |
| 4 | −0.4800 | 0 | 0 |

右列是今天的标签：1 0 1 0。中列是第 11 天那种只看符号的标签：1 1 1 0。两列只有第二行不同，因为只有 0.5897 落在 0 与 0.70 之间。准确率 0.50 的分子是右列里的两个 1，对应 0.8571 和 2.2258，分母是四步，2/4 写成两位小数是 0.50。第 11 天的 0.75 是 3/4，多出来的那一步正是被 0.70 排除的 0.5897。分子差一步，来自定义里多了一条阈值，不是来自预测里多了一个不同的符号。

永远猜涨的预测是长度为 4 的全 1。对右列，命中步数是第一行和第三行，准确率 0.50。对中列，命中步数是前三行，准确率 0.75。同一预测、两套标签、两个准确率。报告 0.50 的时候，0.70 和比较方向「严格大于」一起报告。换成大于等于，或者换成另一个数，定义就换成了另一个目标。今天用的是严格大于 0.70。

第 11 天的 0.75 来自正斜率，而正斜率的方向规则恰好就是永远猜涨。今天不再估计斜率。预测固定成常数 1，用来暴露标签定义：切分一动，准确率就动。0.50 是这条常数在阈值标签上的命中比例。它不是一条新直线的斜率，也不是第四日那个 8.21。

## 拓展领域

分类目标经常被说成「涨或跌」，好像符号是数据里现成的一列。收益是实数。从实数到 0 和 1，中间有一次截断。截断点写在定义里，就和收益本身一样属于目标。两个记录用同一串收盘、同一条永远猜涨，一个用符号，一个用 0.70，得到 0.75 和 0.50。差别在第二步的 0.5897 被分到了哪一边。

说「规则有一半步数是对的」时，一半对应的是 1 0 1 0 里面的两个 1。那两个 1 是 0.8571 和 2.2258。0.5897 这一步价格也涨了，只是没有越过 0.70。在今天的定义里它是 0，永远猜涨在这一步算错。若要抓住的上涨包含 0.5897，今天的标签就不是那个目标，0.50 也不能拿去描述那个目标。切分是定义的一部分。

阈值还可以继续移动。0.70 只是其中一个切分。把切分改高或改低，1 的个数会变，永远猜涨的准确率会跟着变。下一张表专门记录这种移动：同一条常数规则，三条阈值，三个准确率。今天先把一件事固定下来：0.50 这个数的定义里包含着 0.70。

阈值 τ 写进标签 `1{r > τ}`，比较是严格大于。第二步 0.5897 在 τ=0.70 下为 0，在符号标签下为 1——这是今天 0.50 对 0.75 差别的唯一来源。四个收益已固定，改 τ 会改标签列，不会改 always-up 预测列。

把 0.5897 放在数轴上：它在 0 与 0.70 之间，因此「上涨」若定义为超过 0.70，这一步不算上涨，尽管价格为正。业务语言里的「小涨」与「统计上涨类」可以分歧；今天用 0.70 把分歧钉死。第 13 天扫 τ∈{0.50,0.70,0.90}，证明同一预测下准确率可差 0.50。

收益分母是前一日收盘：0.8571 等来自脚本，不要手改四舍五入再重算标签。always-up 预测 `1,1,1,1` 对标签 1 0 1 0 得 2/4=0.50。报告 0.50 时必须同句给出 τ=0.70 与严格大于，否则第二步 0.5897 无法重建。

与第 11 天关系：符号标签上 always-up 为 0.75；今天标签更严，命中率下降。不是模型变聪明或变笨，是目标函数变严。第 14 天在符号标签上给 always-down 0.25，与 always-up 0.75 互补；阈值标签不在该互补表里。

第 22 天硬币 0.5000 是另一基准，用于 77 段符号；不要与今天 0.50 混名——今天 0.50 是 always-up 对阈值标签的比例，不是硬币。命名上写 constant-up accuracy = 0.50 并对照 threshold 0.70。

自检：stdout 四个收益顺序、标签 1 0 1 0、constant-up accuracy = 0.50。禁止写「模型准确率一半」而不说一半相对哪套标签。下一步灵敏度表会显示 0.75/0.50/0.25 三档。
【续】四收益由脚本生成，手算应用分母为前一日收盘。第二步 0.5897 是符号与阈值分歧的唯一台阶；写实验记录时用高亮标这一步，避免读者以为预测模型在第 2 步「改口」。always-up 在阈值标签上的 0.50 不是「比第 11 天退步」，是目标变严。

比较第 13 天三行表时，0.70 行应与本日 0.50 完全一致。若不一致，优先查标签函数是否 strict greater。第 14 天符号基准 0.75 等于 τ=0.50 行，而非 τ=0.70 行——写对照表时勿并错行。

stdout 键 `constant-up accuracy = 0.50` 与 `τ=0.70` 必须同段。禁止省略四收益序列。下一步灵敏度扫 0.50/0.90 端点。
阈值 τ=0.70 与收益 0.8571、0.5897、2.2258、−0.4800 四数一起构成可复现实验。改任一收益一位小数，标签可能变，0.50 可能变——Today 不允许手改。strict `>` 与 `≥` 在 0.5897 对 0.70 无歧义，但对等于 τ 的点未来课会敏感。

与第 18 天 volume median strict 对照：两处都用严格不等式排除边界点（1.2e6 等于 median）。写作模式：门槛写进定义句，准确率写进结果句，中间不插入「感觉上的大涨」。constant-up 0.50 是 always-up 在 1 0 1 0 上的算术，不是新斜率。
【终稿补充】第 12 天把「上涨类」从符号改成收益超过 0.70，四步收益 0.8571、0.5897、2.2258、−0.4800 与 always-up 预测 1 1 1 1 的组合是整课锚点。第二步 0.5897 在符号意义下仍为正，在阈值意义下为负类，这是 0.75 与 0.50 分岔的唯一点。教学时建议把四步画成数轴，在 0.70 处画竖线，标出 0.5897 落在线左、0.8571 与 2.2258 在线右、−0.4800 在零左。读者一眼可见「正收益不等于超过阈值」。报告论文时 Methods 段必须写 `label = 1{r > 0.70}` 与 strict inequality，Results 段才写 constant-up accuracy = 0.50。缺 Methods 中的 τ，Results 的 0.50 不可复现。与第 11 天 3/4 对照：3/4 是符号命中，不是阈值命中；同一 always-up 在符号标签上会是 0.75（第 14 天 always-up 行）。三课连读时，预测列始终不变，变的是标签列定义。第 13 天将在 τ∈{0.50,0.70,0.90} 上扫灵敏度；Today 的中间行 0.70 必须与本日 0.50 一致，否则说明实现或四舍五入出错。代码审查 checklist：`threshold.py` 是否打印四个收益原序、标签 1 0 1 0、constant-up accuracy = 0.50。单元测试可断言第二步标签为 0、第一步与第三步为 1。不要把 0.50 解释成「模型无效」——它是 always-up 在该标签上的精确计数 2/4。有效无效需要相对基准；符号标签基准是 0.75，阈值标签基准需另选或并列说明。第 22 天 coin 0.5000 又是不同分母上的基准，三数不可混排名。交作业时写清：Today 结论不是斜率变化，是标签变严导致命中率下降。下一步灵敏度表会显示 τ 升高时 always-up 准确率单调下降（在本四步样本上）。
