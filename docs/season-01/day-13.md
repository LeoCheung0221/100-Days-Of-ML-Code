# 第 13 天 · 阈值灵敏度

[第一阶段 · 模型](README.md) · 可运行

今天的学习要点：阈值 0.50、0.70、0.90 上，永远猜涨的准确率依次是 0.75、0.50、0.25，阈值上升 0.40，准确率下降 0.50，只报告一个准确率就藏起了它用的那条切分。

## 费曼法讲解

四个收益仍是 0.8571、0.5897、2.2258、−0.4800。预测仍是每一步都交 1。今天只移动那条水平线，线的高度取三个数：0.50、0.70、0.90。

线画在 0.50。0.8571、0.5897、2.2258 都在线以上，−0.4800 在线以下。标签是 1 1 1 0。永远猜涨中前三步，准确率 0.75。

线画在 0.70。0.5897 落到线以下，标签变成 1 0 1 0。永远猜涨中第一和第三步，准确率 0.50。这就是第 12 天的那一个数。

线画在 0.90。0.8571 也落到线以下，只剩 2.2258 在线以上。标签是 0 0 1 0。永远猜涨只中第三步，准确率 0.25。

从 0.50 到 0.90，阈值升高 0.40。准确率从 0.75 到 0.25，下降 0.50。预测的四个 1 一个都没改。下降来自标签里 1 的减少：先是 0.5897 不够高，再是 0.8571 也不够高。2.2258 三次都在线以上，−0.4800 三次都在线以下。中间两个正收益决定了这张表怎么走。

若一份结果只写「准确率 0.50」，它没有说出线画在 0.70，而不是 0.50 或 0.90。同一个预测，换一条线，可以得到 0.75，也可以得到 0.25。单独的 0.50 藏起了切分。

## 核心知识

预测固定为全 1。标签是 `1{r > τ}`，τ 取 0.50、0.70、0.90。准确率是预测与标签相等的比例。

| 阈值 | 高于阈值的收益 | 标签 | 永远猜涨的准确率 |
|---:|---|---|---:|
| 0.50 | 0.8571，0.5897，2.2258 | 1 1 1 0 | 0.75 |
| 0.70 | 0.8571，2.2258 | 1 0 1 0 | 0.50 |
| 0.90 | 2.2258 | 0 0 1 0 | 0.25 |

0.5897 满足 `0.50 < 0.5897 < 0.70`，所以它只在第一行算 1。0.8571 满足 `0.70 < 0.8571 < 0.90`，所以它在前两行算 1，在第三行算 0。2.2258 大于 0.90，三行都算 1。−0.4800 小于 0.50，三行都算 0。

两条差是这张表的尺度：

```text
0.90 − 0.50 = 0.40
0.75 − 0.25 = 0.50
```

阈值上升 0.40，永远猜涨的准确率下降 0.50。这不是一条估计出来的回归斜率，是三行已经算完的表上，端点之差。中间行 0.70 对应 0.50，说明变化穿过中间那一档：每升高一档，就有一个正收益从 1 变成 0，准确率减少 0.25，因为四步里改一类就是 1/4。

报告因此要带上 τ。写准确率 0.75 而不写阈值 0.50，这个 0.75 会和符号标签上的永远猜涨叠在一起。它在这一行确实与符号标签上的 0.75 数字相同，条件是切分取 0.50，并且 0.5897 仍高于这条切分。写准确率 0.25 而不写 0.90，规则看起来像是变了。规则没有变，仍是四个 1。变的是「什么叫做上涨」。

## 拓展领域

这里的灵敏度是标签定义的灵敏度。预测没有待估的参数。四个 1 是事先写死的常数。移动的对象是目标里的截断点。截断点从 0.50 移到 0.70，再移到 0.90，正类的个数从三变成两，再变成一，命中比例从 0.75 变成 0.50，再变成 0.25。

这张表用来拦住一个数被单独拿走。0.50 只在 τ = 0.70 这一行成立。把它摘出去做成标题，标题里就丢掉了产生它的那一行。以后若用别的阈值重做标签，再和这个 0.50 比高下，比的是两个定义。预测在三行里是同一个。

四个收益落在切分的哪一侧，决定了表的形状。今天准确率随阈值升高而下降，是因为永远猜涨把每一行都猜成 1，而升高阈值会关掉一些 1，关掉的那些步就从命中变成不中。若预测不是全 1，某一行从 1 变成 0 可能增加命中。今天不改预测，所以三行的方向是清楚的：切分升高，正类变少，全 1 的命中变少。下降 0.50 是这一个实验的端点差，引用时连同升高的 0.40 一起引用。

只交付一个准确率，等于从三行里任取一行再把阈值涂掉。涂掉之后，0.75、0.50、0.25 无法彼此分辨。切分必须留在结果旁边。

四步收益里，会在这三档之间换边的是 0.5897 和 0.8571。2.2258 高于 0.90，−0.4800 低于 0.50，这两步在三行里类别不变。准确率从 0.75 到 0.50，对应 0.5897 掉出正类；从 0.50 到 0.25，对应 0.8571 再掉出正类。每一级下降都有一个可以指认的收益，而不是四步一起改号。把收益名单和阈值写在同一个准确率旁边，0.75、0.50、0.25 才各自对应一条明确的切分。

三行表共享同一预测向量 `[1,1,1,1]`，只有标签随行变。端点差 0.75−0.25=0.50 对应 τ 升高 0.40，是离散计数效应：每升一档，多一个正收益被划到 0 类，四步中命中率降 0.25。2.2258 三行皆为 1；−0.4800 三行皆为 0——它们不驱动灵敏度，驱动的是 0.5897 与 0.8571 的换边。

单独摘 0.50 而不说 τ=0.70，等于从三行表删行。审稿时若见「上涨准确率 0.50」，必先问阈值。第 12 天那一行在本表中间；第 14 天符号标签的 0.75 等于本表 τ=0.50 行，因 0.5897>0.50。

这不是超参数搜索：τ 三个值都事先列出，不是看完准确率再挑最优 τ。第 23 天强调 rule fixed before count；今天强调 threshold listed before accuracy。后者是标签定义灵敏度，不是学习率网格搜索。

0.5897 的区间 `0.50 < r < 0.70` 要会手算验证。0.8571 在 `0.70 < r < 0.90` 区间，故第二档为 1、第三档为 0。写文档时用脚本打印的三行，不要另造 τ=0.60 插值行，除非另开实验。

与分类基准：always-up 在符号标签 0.75；在 τ=0.90 标签仅 0.25。若只报 0.25 而不说规则仍是 always-up，读者会以为换了模型。三行表的力量在于固定预测、扫目标。

复现 `sensitivity.py`，核对 0.75、0.50、0.25 与 0.50/0.70/0.90 对齐。交作业写清：预测不变、标签变、准确率变。禁止把 0.50 写成「比随机好」——随机基准尚未在本课 five-point 设定中出现。
【续】三行表的 0.40 与 0.50 差是离散计数，不是回归斜率。引用「阈值升 0.40、准确率降 0.50」时必须同时给出三行 τ。中间行 0.70 的 0.50 是第 12 天单点；摘出时须带 τ。

2.2258 与 −0.4800 在三行中类别稳定，教学时可先讲这两步「不驱动灵敏度」，再讲 0.5897、0.8571 换边。预测恒为 1 意味着准确率等于标签中 1 的比例；τ 越高，1 越少，always-up 命中越低。

脚本 `sensitivity.py` 三准确率与三阈值顺序固定。写文档忌造第四阈值行而不跑脚本。下一步常数基准章回到符号标签 0.75/0.25。
灵敏度表用于方法学而非选股结论。三行 τ 是事先枚举，不是最优化结果。若读者问「为何选 0.70」，答：课程在第 12 天固定该点，第 13 天展示邻域；不是数据驱动挑 τ。0.25 行说明 even always-up 在过严标签上可低于 0.5。

写论文时把 Table 放在正文：列 τ、标签模式、accuracy；脚注写预测恒 1。禁止把 0.75−0.25=0.50 称为 slope。四收益中 2.2258>0.90 是第三行唯一正类来源之一（另一正类 0.8571 在 τ=0.50 行）。逐行核对脚本 stdout 与表一致。
【终稿补充】灵敏度三行表是「固定预测、移动目标」的标准展示。τ 从 0.50 到 0.90 升高 0.40，always-up 准确率从 0.75 到 0.25 下降 0.50，因为每升高一档，多一个正收益被划到 0 类，四步中占 1/4。0.5897 只在第一行 τ=0.50 时为 1；0.8571 在前两行时为 1、第三行为 0；2.2258 三行皆为 1；−0.4800 三行皆为 0。手算练习：逐行写标签向量，再与预测 1 1 1 1 比相等个数。第一行 3/4=0.75，第二行 2/4=0.50，第三行 1/4=0.25。禁止把三行准确率平均成「0.50 平均」——每行对应不同 τ，是不同实验条件。写文档时 Table caption 必须含「prediction: always up」。单独摘 0.50 而不写 τ=0.70 等于删掉 Table 第二行标识。第 12 天单点实验是本表中间行；若两行 0.50 不一致，优先查收益或比较符。与第 14 天关系：τ=0.50 行准确率 0.75 等于符号标签 always-up，因 0.5897>0.50；不是等于 τ=0.70 行。第 18 天 median strict 与 threshold strict 写作模式相同：边界点排除。复现 `sensitivity.py` 三对 (τ, accuracy)。英文版数字与中文绑定。下一步基准章回到符号标签 0.75/0.25，勿把本表 0.25 行与 always-down 混淆——本表 0.25 仍是 always-up 在 τ=0.90 标签上的命中，不是 always-down。
