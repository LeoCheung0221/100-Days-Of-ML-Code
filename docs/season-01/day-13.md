# 第 13 天 · 阈值灵敏度

[第一阶段 · 模型](README.md) · 可运行

今天的学习要点：阈值 0.50、0.70、0.90 上，永远猜涨的准确率依次是 0.75、0.50、0.25，阈值上升 0.40，准确率下降 0.50，只报告一个准确率就藏起了它用的那条切分。

## 费曼法讲解

四个收益仍是 0.8571、0.5897、2.2258、−0.4800。预测仍是每一步都交 1。今天只移动那条水平线，线的高度取三个数：0.50、0.70、0.90。

线画在 0.50。0.8571、0.5897、2.2258 都在线以上，−0.4800 在线以下。标签是 1 1 1 0。永远猜涨中前三步，准确率 0.75。

线画在 0.70。0.5897 落到线以下，标签变成 1 0 1 0。永远猜涨中第一和第三步，准确率 0.50。这就是第 12 天的那一个数。

线画在 0.90。0.8571 也落到线以下，只剩 2.2258 在线以上。标签是 0 0 1 0。永远猜涨只中第三步，准确率 0.25。

从 0.50 到 0.90，阈值升高 0.40。准确率从 0.75 到 0.25，下降 0.50。预测的四个 1 一个都没改。下降来自标签里 1 的减少：先是 0.5897 不够高，再是 0.8571 也不够高。2.2258 三次都在线以上，−0.4800 三次都在线以下。中间两个正收益决定了这张表怎么走。

若一份结果只写「准确率 0.50」，它没有说出线画在 0.70，而不是 0.50 或 0.90。同一个预测，换一条线，可以得到 0.75，也可以得到 0.25。单独的 0.50 藏起了切分。

## 核心知识

预测固定为全 1。标签是 `1{r > τ}`，τ 取 0.50、0.70、0.90。准确率是预测与标签相等的比例。

| 阈值 | 高于阈值的收益 | 标签 | 永远猜涨的准确率 |
|---:|---|---|---:|
| 0.50 | 0.8571，0.5897，2.2258 | 1 1 1 0 | 0.75 |
| 0.70 | 0.8571，2.2258 | 1 0 1 0 | 0.50 |
| 0.90 | 2.2258 | 0 0 1 0 | 0.25 |

0.5897 满足 `0.50 < 0.5897 < 0.70`，所以它只在第一行算 1。0.8571 满足 `0.70 < 0.8571 < 0.90`，所以它在前两行算 1，在第三行算 0。2.2258 大于 0.90，三行都算 1。−0.4800 小于 0.50，三行都算 0。

两条差是这张表的尺度：

```text
0.90 − 0.50 = 0.40
0.75 − 0.25 = 0.50
```

阈值上升 0.40，永远猜涨的准确率下降 0.50。这不是一条估计出来的回归斜率，是三行已经算完的表上，端点之差。中间行 0.70 对应 0.50，说明变化穿过中间那一档：每升高一档，就有一个正收益从 1 变成 0，准确率减少 0.25，因为四步里改一类就是 1/4。

报告因此要带上 τ。写准确率 0.75 而不写阈值 0.50，这个 0.75 会和符号标签上的永远猜涨叠在一起。它在这一行确实与符号标签上的 0.75 数字相同，条件是切分取 0.50，并且 0.5897 仍高于这条切分。写准确率 0.25 而不写 0.90，规则看起来像是变了。规则没有变，仍是四个 1。变的是「什么叫做上涨」。

## 拓展领域

这里的灵敏度是标签定义的灵敏度。预测没有待估的参数。四个 1 是事先写死的常数。移动的对象是目标里的截断点。截断点从 0.50 移到 0.70，再移到 0.90，正类的个数从三变成两，再变成一，命中比例从 0.75 变成 0.50，再变成 0.25。

这张表用来拦住一个数被单独拿走。0.50 只在 τ = 0.70 这一行成立。把它摘出去做成标题，标题里就丢掉了产生它的那一行。以后若用别的阈值重做标签，再和这个 0.50 比高下，比的是两个定义。预测在三行里是同一个。

四个收益落在切分的哪一侧，决定了表的形状。今天准确率随阈值升高而下降，是因为永远猜涨把每一行都猜成 1，而升高阈值会关掉一些 1，关掉的那些步就从命中变成不中。若预测不是全 1，某一行从 1 变成 0 可能增加命中。今天不改预测，所以三行的方向是清楚的：切分升高，正类变少，全 1 的命中变少。下降 0.50 是这一个实验的端点差，引用时连同升高的 0.40 一起引用。

只交付一个准确率，等于从三行里任取一行再把阈值涂掉。涂掉之后，0.75、0.50、0.25 无法彼此分辨。切分必须留在结果旁边。

四步收益里，会在这三档之间换边的是 0.5897 和 0.8571。2.2258 高于 0.90，−0.4800 低于 0.50，这两步在三行里类别不变。准确率从 0.75 到 0.50，对应 0.5897 掉出正类；从 0.50 到 0.25，对应 0.8571 再掉出正类。每一级下降都有一个可以指认的收益，而不是四步一起改号。把收益名单和阈值写在同一个准确率旁边，0.75、0.50、0.25 才各自对应一条明确的切分。
