# 第 15 天 · 两类误分

[第一阶段 · 模型](README.md) · 可运行

今天的学习要点：永远猜涨把「上涨判成下跌」记成 0、把「下跌判成上涨」记成 1，准确率 0.75 把这两格合成一个数，两格都要保留。

## 费曼法讲解

符号标签仍是四步里的 1 1 1 0，来自收益 0.8571、0.5897、2.2258 为正、−0.4800 为负。永远猜涨的预测是 1 1 1 1。

把结果画成四格，行是实际，列是预测。实际上涨、预测下跌：这一格是 0。永远猜涨从不写出下跌，所以它没有把任何一次上涨判成下跌。实际下跌、预测上涨：这一格是 1。四步里只有最后一步是下跌，收益 −0.4800，预测却写了上涨。

另外两格可以由这四步数回来。误差一共是 0 + 1 = 1 步。四步减去这一步，剩下三步被说中，3/4 = 0.75。这三步都落在「实际上涨、预测上涨」，因为那一个误差已经占用了唯一的下跌。「实际下跌、预测下跌」是 0：那一次下跌没有被判成下跌。

0.75 把这四格收成一个比例。收完之后，看见的是命中占了四分之三，看不见误差全部坐在「下跌判成上涨」，也看不见「上涨判成下跌」是 0。0 这一格并不是规则逐日辨认出了每一次上涨。规则没有下跌这个输出，这一格在任何样本上都会是 0。1 这一格才是这四步里真正发生的那次不一致。两格都要留下。只留 0.75，两类误分就无法再分开。

## 核心知识

永远猜涨，符号标签：

```text
up called down = 0
down called up = 1
accuracy = 0.75 = (4 − 0 − 1) / 4
```

|  | 预测下跌 | 预测上涨 |
|---|---:|---:|
| 实际上涨 | 0 | 3 |
| 实际下跌 | 0 | 1 |

右下角是下跌判成上涨，等于 1。左上角是上涨判成下跌，等于 0。右上角的 3 是三个正收益被判成上涨。左下角是 0，因为仅有的那次下跌进了右下角。

准确率只用被说中的步数，再除以 4：

```text
(3 + 0) / 4 = 0.75
```

从 0.75 回不去这两格。任何一个满足「说中三步、说错一步」的四格表都给出 0.75。误差可以是上涨判成下跌，也可以是下跌判成上涨。今天的表是后一种，而且数量是 1 对 0。换成一条也会写出 0 的规则，同样的 0.75 可以对应别的两格。所以 0.75 不能代替这两格。

永远猜涨还有一个先于这四步具体数值的结构：预测列里没有 0，因此「上涨判成下跌」的计数恒为 0，与收益取值无关。这一格的 0 是规则的值域造成的。它不提供「规则很少错过上涨」的额外证据。错过上涨在这个规则下无法被记录，因为规则拒绝预测下跌。能够随样本变化的误差格是「下跌判成上涨」。今天它等于 1，等于样本里下跌的步数。下跌有几步，这一格就是几，只要规则仍是全 1。

第 14 天的 0.75 和 0.25 是两个准确率。今天把其中的 0.75 拆开。拆开之后，摘要要包含两格：0 和 1。

## 拓展领域

两类误分对应两种不同的记录。把上涨判成下跌，是一次实际为正的收益被放进了下跌。把下跌判成上涨，是一次实际为负的收益被放进了上涨。一个每一步都猜涨的规则，只会积累后一种记录。前一种记录保持为 0。若评价只看准确率，这种规则在三正一负的标签上显示 0.75，同时把它唯一的错误类型收进同一个比例。

两格的代价若不相同，一个数就更不够。今天不给两格规定价格。需要先有两格，权重才有地方可乘。0 乘任何权重仍是 0，1 乘权重就是那一次「下跌判成上涨」的全部代价。准确率 0.75 既不保留权重，也不保留哪一格非零。先把格子写全。

同一准确率、不同的格，也会改变后面几天对程度分数的读法。一条每步都交很高上涨分数、并且从不交下跌的规则，在「上涨判成下跌」上也会是 0。这个 0 与分数高不高无关，与它是否输出过下跌有关。今天的规则连分数都没有，只有硬的 1。它已经表明：0.75 必须和两格一起出现。两格是 0 和 1。缺一格，另一格的含义就变了。
