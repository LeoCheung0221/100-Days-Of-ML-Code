# 第 16 天 · 上涨程度

[第一阶段 · 模型](README.md) · 可运行

今天的学习要点：斜率 3.27 送进 sigmoid 得到 0.9634，四步都贴这同一个分数，仿射直线的一日差分是常数，因此这个分数不能把四步按置信排出高下。

## 费曼法讲解

前几天的方向输出是硬的 1：每一步都猜涨。今天在这个 1 前面放一个程度。做法是把已经估出的斜率 3.27 送进 sigmoid。sigmoid 把实数收成 0 和 1 之间的数。3.27 是一个正数，收出来是 0.9634。

这个 0.9634 只依赖斜率。斜率是整条直线 `ŷ = 3.27x − 1.29` 的一个系数，不是某一步的收益。四步的实际收益并不相同，它们是 0.8571、0.5897、2.2258、−0.4800。程度分数不读这四个数。它读 3.27，读一次，然后把结果复制到每一步。四步旁边都写着 0.9634。

复制的原因在直线的形状里。仿射直线的一日差分是

```text
Δŷ_t = 3.27
```

对 t = 2, 3, 4, 5 都成立。差分不随 t 改变，sigmoid 的输入就不随 t 改变，输出也就不随 t 改变。四步的程度上没有高低。把它们按这个分数排序，四步并列。一个每步都相同的分数，不能用来表示「这一步比那一步更有把握」。

0.9634 也还不是这四步里上涨发生的频率。频率要去数有几步收益为正，那是下一章的核对。今天的精确陈述停在排序：因为仿射一日差分是常数，sigmoid(3.27) = 0.9634 这一个数覆盖四步，它不能把四步按置信分开。

## 核心知识

```text
σ(z) = 1 / (1 + exp(−z))
z = β₁ = 3.27
σ(3.27) = 0.9634
```

四步的分数向量是

```text
0.9634, 0.9634, 0.9634, 0.9634
```

它是常数向量。常数向量的任意两步之差是 0。因此不存在一个步的下标，使得该步的分数严格大于另一步。置信排序要求至少有两个不同的值。这里没有。

输入之所以是常数，是因为仿射函数对 t 的差分为斜率，而斜率不是 t 的函数。若分数使用了每一步自己的信息，输入里应该出现那一步的收益，或那一步的价格残差。今天的输入里只有 3.27。第四日绝对残差 8.21 的那一步，和第五日绝对残差 4.66 且方向不中的那一步，都不会把 0.9634 改成两个数。程度分数对这两日写成同一个数。

0.9634 也不是第 15 天那张四格表里的某一格。四格表计数的是硬分类：永远猜涨的误差在「下跌判成上涨」为 1，在「上涨判成下跌」为 0。sigmoid 没有先做这个硬分类再去数。它把斜率映射成一个介于 0 和 1 之间的数，再复制四次。映射是单调的：斜率越大，这个数越靠近 1。它不检查四步里面有几步确实为正。检查那件事需要另一个数，和 0.9634 并排。

不能排序的直接后果是：这四步无法按「更像上涨」分出第一和第二。若只要留下分数最高的一步，这条规则交不出那一步，因为四步的分数相同。交得出的只有一个共同的程度 0.9634，以及它来自斜率而不是来自单步收益。

## 拓展领域

把硬标签换成一个 0 到 1 的分数，常常被说成规则开始表达置信。置信要能在不同的情形之间变动，变动才构成区分。一个在四步上都打印 0.9634 的规则，表达的是整条直线的斜率有多大，不是这一步的涨跌有多清楚。斜率已经在第 11 天决定了方向：正斜率等于每一步都猜涨。sigmoid 把这个正号变成一个靠近 1 的小数。靠近 1 的程度由 3.27 的大小决定，不由四步收益彼此差多少决定。

因此，0.9634 的读法停在「四步共用的程度上写着 0.9634」。它不给出四步各自不同的把握。频率还没有计算。四步的把握在这个定义下相同。若以后改用单步特征，分数才可能四步不同，排序才可能存在。今天的特征是整段样本上的一个斜率，排序不存在。

常数分数还有一个和基准相连的读法。第 14 天的永远猜涨在符号上每步都交 1。今天在程度上每步都交 0.9634。两者都是不随 t 变化的输出。差别是 1 和 0.9634 这两个字面值。字面值变了，排序能力没有出现。评价这个分数时，单独问它能否区分四步。答案是不能。不能区分，就不能用它做「挑出更有信心的那一天」。
