# 第 20 天 · 噪声列

[第一阶段 · 模型](README.md) · 可运行

今天的学习要点：噪声用事先固定的种子 0，在 t = 1..4 上拟合、在 t = 5 上评分，样本内残差平方和从 42.0500 降到 26.7061，留出绝对误差从 11.6500 升到 18.1513，样本内的下降不是改进。

## 费曼法讲解

五个会话仍是收盘 2.1、3.9、6.2、20.0、10.4。今天把估计和评分拆开。t = 1、2、3、4 用来拟合，对应收盘 2.1、3.9、6.2、20.0。t = 5 不进入系数，只用来评分，收盘是 10.4。

先只放时间。在前四个点上做一条带截距的直线，把四个拟合值和四个收盘的差平方后相加，得到样本内残差平方和 42.0500。再看 t = 5：这条直线在第五日的预测与 10.4 的绝对距离是 11.6500。这是没有噪声列时的两个数。样本内的那个描述前四日贴得有多紧，留出的那个才是第五日的误差。

然后加一列噪声。噪声在拟合之前就定下来：随机数种子是 0，五个会话各有一个事先抽好的数，不因看过第五日的误差而重抽。前四个噪声数和时间、截距一起进入 t = 1..4 的最小二乘。列空间变大了，前四日的残差平方和降到 26.7061。第五日评分时才用到第五个噪声数。留出绝对误差升到 18.1513。

训练平方和从 42.0500 降到 26.7061。第五日的绝对误差从 11.6500 升到 18.1513。要交的分数是留出误差，而它变差了。样本内那一截下降不是改进。

## 核心知识

```text
noise seed = 0, fixed in advance
fit on t = 1..4
score on t = 5
```

|  | 无噪声列 | 有噪声列 |
|---|---:|---:|
| 样本内残差平方和 | 42.0500 | 26.7061 |
| 留出绝对误差 | 11.6500 | 18.1513 |

无噪声的拟合是时间加截距，系数只用前四个收盘。有噪声的拟合在这两列之外加上种子为 0 的那一列，系数仍然只用前四个会话。第五日的收盘 10.4 不参与任何一边的最小二乘。第五日的噪声只在已经估完系数之后，乘上自己的系数，加进预测，再和 10.4 取绝对差。

更大的列空间可以降低训练平方和。时间加截距所能达到的 42.0500，在更大的空间里仍然可达：把噪声的系数设为 0 就回到原来的拟合。最小二乘还可以使用噪声列，于是平方和可以更低。今天它确实更低，是 26.7061。这个下降是列空间变大之后的结果，不是第五日变得更好预测的证据。第五日的数是 18.1513 对 11.6500，有噪声的一边更大。

26.7061 也不是 0。四个训练点上，时间、噪声、截距共三列，平方和下降了，但没有下降到把四个点完全重合。即便如此，留出误差仍然变大。所以样本内更小，不能被读成留出误差更小。留出这一侧今天只有一个点，t = 5，它的绝对误差是计入分数的数，而这个数从 11.6500 变到了 18.1513。

种子事先固定，是为了这条噪声列不是对着第五日挑出来的。没有用留出误差去选择种子。即使这样，这一次抽出的列仍然使留出误差变大。更大的列空间可以降低训练平方和。这句话今天写成 42.0500 到 26.7061。计入的分数是留出误差，它变差了。样本内的下降不是改进。

## 拓展领域

加列是把训练误差做小的直接办法。新的列只要在四个训练点上提供一个新方向，最小二乘就会使用它，只要它能减少前四日的平方和。噪声列是种子 0 定下的一串数。减少发生了，从 42.0500 到 26.7061。使用这个方向之后，t = 5 的绝对误差从 11.6500 增到 18.1513。

模型比较若只把训练残差平方和较小的那一个称为更好，今天会把带噪声的拟合选中。那个选择与留出评分相反。留出评分里，11.6500 小于 18.1513，没有噪声的一边误差更小。两个排序都是这张表里的事实。哪一个排序被叫做分数，事先写明。今天写明的是留出绝对误差。

这也给同一样本上先拟合再评分一个边界。在同一些点上拟合、再在同一些点上数残差，和今天的训练平方和属于同一类对象：这些点已经参与了系数。今天把第五日从系数里拿出去之后，训练平方和的下降不再被当作成绩。成绩看 18.1513 和 11.6500。噪声列把训练误差做小、把留出误差做大。样本内的下降不是改进。

种子固定并不把这一次的结果说成每一串噪声都会伤害留出点。它保证的是：这一列在看见留出结果之前已经确定，今天报告的变差不是挑种子挑出来的。就这一次已经确定的列而言，留出绝对误差变大了。结论停在这次运行。这一个结果已经足够说明：训练平方和从 42.0500 降到 26.7061，可以与留出误差从 11.6500 升到 18.1513 同时发生。
