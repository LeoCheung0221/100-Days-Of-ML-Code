# 第 26 天 · 随机切分

[第一阶段 · 模型](README.md) · 可运行

今天的学习要点：种子是 1，训练比例是 0.70。在训练行上把今日收益对昨日收益做最小二乘，测试集上的方向准确率是 0.4583。这个数是对照。今天只把它标成对照。

## 费曼法讲解

样本仍是 AAA 上有限复权收盘的简单收益。昨日收益是自变量，今日收益是因变量，一对滞后构成一行。第 25 天把昨日收益原样当作预测，斜率和截距都不估。今天改成在一部分行上估计一条直线，再在其余行上看符号。

哪些行进入训练，由种子 1 的随机数决定。训练比例写死为 0.70，无放回抽取。没有抽中的行是测试。直线只在训练行上做普通最小二乘：今日收益对昨日收益，得到一个斜率和一个截距。测试行套用这条直线，比较预测收益和实际收益的符号。测试方向准确率印成 0.4583。

打印的最后一行是 this number is the control。0.4583 今天的身份是对照。它还没有被放到按时间切开的测试准确率旁边。程序给它的句子只有这一句：这个数是对照。种子、比例和这个准确率，就是今天交出来的全部。

第 25 天的 0.4675 是全样本上「预测等于昨日收益」的符号命中率。今天的 0.4583 是另一条对象：斜率在训练行上估出来，符号只在测试行上数。两个四位小数接近，回答的不是同一次计数。今天不把 0.4583 和第 25 天的 0.4675 合成一个结论，也不把它和后面才会出现的时间切分放在同一句里。

## 核心知识

```text
split = random, seed 1, train fraction 0.70
test direction accuracy = 0.4583
this number is the control
```

记一行为 `(x_t, y_t) = (r_{t−1}, r_t)`。训练掩码由种子 1 无放回抽出，抽出的比例是 0.70。在训练行上，

```text
ŷ = β̂₀ + β̂₁ x
```

系数只由训练行的最小二乘决定。测试方向准确率是测试行上 `sign(y) = sign(ŷ)` 的比例，印成 0.4583。

0.4583 的定义里有三件已经写死的事：种子 1、训练比例 0.70、以及分数只在测试行的符号上计算。换种子会换成另一批训练行，准确率可以变成别的四位小数。今天不换。打印出来的对照就是这一个 0.4583。

这个数今天不与时间切分并排。并排是下一步的工作。今天的句子停在程序已经印出的那一行：this number is the control。

## 拓展领域

随机切分把行打散之后再估系数，测试行在时间上可以落在训练行的前面，也可以落在后面。对一条按日期排列的收益序列，这种打散回答的是：在这一种抽法下，测试符号准确率印成多少。它不回答「训练全部发生在测试之前」时准确率是多少。那一问留给下一天。今天若提前把两个数写在一起，对照就不再是对照，而变成一次比较的一侧。程序没有做这次比较。

0.4583 也不是第 22 天那种不估参数的滞后符号。滞后符号的规则在计数之前就已经是「昨日的符号」，分母是全部可比较的段。今天的符号来自一条只看见训练行的直线。测试行的标签没有进入 `β̂`。这是它能够被叫做测试准确率的原因。它被叫做对照，是因为今天的笔记只给它这一个身份。

种子写在程序里，是为了让再跑一次仍然抽出同一批行。比例 0.70 同样写死。两者都不是看到 0.4583 之后再调的旋钮。对照的数值因此可以复读：同一文件、同一种子、同一比例，测试方向准确率仍是 0.4583。今天不再给 0.4583 加第二句身份。

