# 第 28 天 · 当日最高价

[第一阶段 · 模型](README.md) · 可运行

今天的学习要点：列 `high` 标成 FORBIDDEN。收盘对当日最高价的样本内 RSS 是 31.8715，收盘对昨日收盘的样本内 RSS 是 35.5233。下降 3.6518 来自同一根 K 线，不是来自一个预测。这里更低的 RSS 不是成绩。

## 费曼法讲解

仍用 AAA 上收盘有限的行。要解释的是当日收盘。两条样本内直线并排，分母是同一批从第二行起的观测，这样昨日收盘才存在。第一条用当日最高价当自变量。最高价和收盘写在同一行、同一天。第二条用昨日收盘当自变量。昨日收盘写在前一行。

第一条的残差平方和是 31.8715。第二条是 35.5233。35.5233 减去 31.8715 等于 3.6518。平方和下降了 3.6518。下降的那一列是当日最高价。脚本把这一列标成 FORBIDDEN。最高价与收盘来自同一根 K 线：这一天的高点已经含有这一天价格走到过哪里的信息，收盘是同一天的另一个价。用它拟合收盘，样本内可以更贴，贴合来自同一根 K 线，不是来自一个在收盘形成之前就能拿来用的预测。

昨日收盘则是前一个交易日已经写下的数。它的 RSS 更高，是 35.5233。更高不使它变成禁止列，更低也不使 31.8715 变成成绩。成绩要回答的是一条可以用过去信息做的预测有多好。31.8715 回答的是同一天的两个价格有多近。把下降的 3.6518 当成改进，就是把同一根 K 线上的贴近当成了预报。

## 核心知识

```text
column high = FORBIDDEN
in-sample RSS close~high = 31.8715
in-sample RSS close~lagged close = 35.5233
```

两条普通最小二乘都在样本内，都带截距：

```text
close_t = a + b · high_t + e_t
close_t = c + d · close_{t−1} + u_t
```

`high_t` 与 `close_t` 同行。`close_{t−1}` 来自前一行。残差平方和

```text
RSS(close ~ high) = 31.8715
RSS(close ~ lagged close) = 35.5233
35.5233 − 31.8715 = 3.6518
```

3.6518 是同一批行上、样本内平方和的下降。它不是留出日上的误差，也不是方向命中。列 `high` 被标成 FORBIDDEN，因为用它解释的是同一个交易日的收盘。更低的 31.8715 不是成绩。允许留下来作参照的样本内平方和，是用昨日收盘的 35.5233。即便如此，35.5233 仍是样本内的平方和，今天也不把它单独升成一个预测成绩。今天要钉住的是：下降的那 3.6518 来自同一根 K 线。

## 拓展领域

同一行里的价格字段共享这一天的成交区间。最高价是区间的上端，收盘是区间里的一个点。上端离收盘往往不远，所以 `close ~ high` 的样本内平方和可以低于 `close ~ lagged close`。31.8715 低于 35.5233，差 3.6518，就是这种同日几何在平方和上的体现。几何上更近，不产生一条可以在开盘前提交的预测。

禁止列的判定看信息的日期，不看平方和的大小。若只按 RSS 挑选列，31.8715 会被当成更好的拟合留下来，FORBIDDEN 会被拿掉。程序先把列标成禁止，再打印两个平方和，顺序本身说明 31.8715 不能反过来为这一列开禁。下降 3.6518 被展示出来，是为了让同日信息的平方和优势可见，同时不把它写入成绩。

3.6518 要和两列的日期放在一起读。31.8715 使用的最高价与收盘是同一天。35.5233 使用的收盘来自前一天。平方和较小的那一次，信息的日期并没有更早，它与被解释的收盘写在同一行。因此这次下降不能记成预测变好。FORBIDDEN 标在 high 上，是把这一列从可以当作预测输入的名单里拿掉。拿掉之后 31.8715 仍然可以打印，用来展示同日价格把样本内平方和压低了多少。打印不等于记分。记分需要的自变量，在收盘写下之前就已经确定。昨日收盘满足这一点。当日最高价不满足。

第 29 天换一种更安静的泄漏。那里的两份 RSS 几乎贴在一起。今天的两份差了 3.6518，差距明显，识别仍然不靠「谁更小」，而靠最高价与收盘写在同一行。谁更小只是同日信息的一个后果。后果可以很大，像今天的 3.6518，也可以很小。识别依据都是自变量里有没有当时还不该使用的价格。

与第 27 天切分题的边界：切分决定哪些行进训练，FORBIDDEN 决定哪些列不能进设计矩阵。即使时间切分完全正确，把 `high_t` 放进 `X` 仍会在样本内把 RSS 从 35.5233 拉到 31.8715。3.6518 的下降因此不能记成「时间切分下的预测改进」。第 40 天会把本日列入泄漏清单，future=yes，更高的样本内贴合不是结果。

量化报告里常见误读：用样本内 RSS 或 R² 排序特征，自动保留 31.8715 那一列。今天的顺序是先 FORBIDDEN，再打印两个 RSS，是在教读者倒过来——先信息集，再数值。若做留出，最高价在留出日上同样不可用，因为留出日的 `high` 与 `close` 仍同属一根已走完的 K 线，只是留出使样本内/外的划分不同，并不把同日信息变成合法预测。

手算直觉：若收盘常靠近当日高位，则 `close ≈ high` 的样本内回归会显得很贴。贴的原因是同一时刻的两个价，不是提前知道收盘。第 34 天的后向填 9.8971 是「把未来价写进当天行」；第 28 天是「把同根 K 线的另一个价写进方程」。两者 future 标记在第 40 天都会是 yes，机制不同，都不能进结果表。
