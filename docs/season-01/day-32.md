# 第 32 天 · 六十日窗口

[第一阶段 · 模型](README.md) · 可运行

今天的学习要点：仍是预测最后一个复权收盘。六十日斜率是 0.0353，绝对失手是 0.4426。三日斜率仍是 −0.1195，绝对失手仍是 0.0867。长窗口还停在更早的斜率上，这一天离收盘更远。

## 费曼法讲解

终点和昨天相同。最后一个复权收盘仍然只用来对答案。三日直线还是终点前三个交易日，斜率 −0.1195，绝对失手 0.0867。六十日直线改用终点前六十个交易日。斜率 0.0353，符号为正，和三日相反。把这条六十日直线放到最后那个时点，绝对失手是 0.4426。

0.4426 大于 0.0867。在这一个收盘上，长窗口离得更远。六十日没有跟着最近三个交易日把斜率改成 −0.1195，外推值还留在 0.0353 这条更早的正斜率上，和最新收盘的距离被拉大到 0.4426。这一天的距离说明长窗口还坐在旧斜率上。它不给窗口长度发一个总的精度名次。六十日在这一天更远，三日在这一天更近，两句都只覆盖这一个时点。

## 核心知识

六十日切片是终点前六十个时点，三日切片仍是终点前三个时点。终点的复权收盘不进斜率。

```text
sixty-day slope = 0.0353
three-day slope = -0.1195
sixty-day absolute miss = 0.4426
three-day absolute miss = 0.0867
```

和昨天并排着读。二十日斜率 0.0251，绝对失手 0.1506。六十日斜率 0.0353，绝对失手 0.4426。窗口从二十日加到六十日，斜率仍为正，这一天的绝对失手从 0.1506 增到 0.4426。加进去的是更早的交易日，它们把直线按在旧方向上。三日斜率 −0.1195 则是最近三个点自己的方向。三行数字回答三件不同的事：局部方向、二十日已经形成的斜率、六十日仍在使用的更早斜率。每一行的失手只属于那个信息集在这一个时点上的外推。

## 拓展领域

把窗口从二十日拉到六十日，改变的是设计矩阵里的行，不是最后那个收盘。行一多，早期价格对正规方程的贡献还在，斜率不容易被末端三个点翻转。末端的三日斜率已经是 −0.1195，六十日的斜率仍是 0.0353。外推值继续沿着旧的上升方向走，和已经转向的最新收盘拉开到 0.4426。三日窗口没有那些较早的行，斜率就是末端自身的 −0.1195，距离收到 0.0867。

0.4426 是旧斜率在这一天的停驻距离。把它读成「长窗口永远更差」，和昨天把 0.0867 读成「三日更准」，用的是同一个时点的残差。研究里若要比较 3、20、60 这三档，比较的区间要事先写死，三档都在同一段留出交易日上报告失手，而且不能看完失手再改档。今天的脚本没有那段区间。它把六十日和三日放在同一个终点上，让旧斜率的停驻变成一个可以核对的距离。

0.0353 和 −0.1195 的符号差，比 0.4426 和 0.0867 的距离差更先说明信息集。六十个交易日里较早的价格仍留在方程里，末端三个交易日的转向没有把斜率从正号拉到负号。两个距离都只描述这一个收盘。把 0.4426 写成六十日窗口的典型误差，或者把 0.0867 写成三日窗口的典型误差，都超出了今天这一次打印。

六十日的 0.0353 和三日的 −0.1195 用的是同一个终点、同一条复权收盘，差别只在切片有多长。0.4426 是六十个交易日的外推离这个收盘的绝对距离，0.0867 是三个交易日的外推离同一个收盘的绝对距离。两个失手已经各占一行。长窗口这一天更远，就停在 0.4426 这一行；短窗口追的局部方向，就停在 −0.1195 这一行。昨天的二十日斜率 0.0251、绝对失手 0.1506 也留在它自己的打印里，不并进今天的名次。下一题离开窗口长度，去看标准化用的均值和标准差是从训练段来的，还是把测试段也看进去了。
