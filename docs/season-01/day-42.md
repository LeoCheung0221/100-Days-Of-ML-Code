# 第 42 天 · 岭回归

[第一阶段 · 模型](README.md) · 可运行

今天的学习要点：同一段 AAA 复权收盘上，惩罚只加在斜率，λ = 20000，截距自由。普通最小二乘斜率是 0.0299，岭回归斜率是 0.0201。直线被要求少倾斜 0.0098。

## 费曼法讲解

第 41 天的直线趴在 79 个复权收盘上，六位小数的斜率是 0.029901，四位小数印刷就是 0.0299。今天不删点。今天在正规方程的斜率那一格上加一个正数，让倾斜付出代价，再把新的斜率读出来。

设计矩阵有两列。第一列是会话序号 t，第二列是常数 1。普通最小二乘解的是 XᵀX β = Xᵀy。岭回归这一版只改左上角：XᵀX 的 (1,1) 元，也就是 Σt²，再加上 λ。截距所在的那一格不加任何数。截距仍要去配合这条被压过的斜率，它没有自己的惩罚。脚本里的 λ 是 20000。

加完之后，斜率从 0.0299 收到 0.0201。差是 0.0098。同一段复权收盘，同一条横轴，直线被要求每过一个会话少抬 0.0098 个价格单位。0.0201 仍是正的。少掉的是倾斜里的 0.0098。

λ 的尺度要对着 Σt² 看。79 个会话序号的平方和已经很大。把 20000 换成 50，加进去的数相对这份平方和可以忽略，斜率会留在最小二乘旁边。50 不是今天的惩罚，也不是第 49 天的惩罚。两天打印和使用的都是 20000，而且都只加在斜率上。

## 核心知识

估计样本是第 41 天那 79 个复权收盘，空白行已经丢掉。不设训练切点。惩罚写进 Gram 矩阵：

```text
(XᵀX)₁₁  ←  Σt² + 20000
(XᵀX)₂₂  ←  n          （截距，不加惩罚）
```

然后解线性方程。截距是自由参数，它的方程里没有 λ。

```text
lambda = 20000, penalty on the slope only
ols slope   = 0.0299
ridge slope = 0.0201
tilt reduction = 0.0299 − 0.0201 = 0.0098
```

0.0299 是第 41 天斜率 0.029901 收到四位小数的印刷。两天是同一次普通最小二乘，精度不同。岭回归的 0.0201 是新的估计。少倾斜的 0.0098 用这两位印刷斜率相减得到，报告时带上这两个被减数。

惩罚抬高的是斜率方向的曲率，所以斜率的绝对值会被拉向 0。截距不在惩罚里，不能把 0.0201 读成「截距也被乘了一个收缩系数」。脚本没有打印截距。今天交出去的数字是两个斜率。

样本内平方和会因为斜率被拉开而上升。那是惩罚的直接后果，数值留到第 46 天，和直线、树放在同一张表里。今天不把那个平方和提前写成成绩。

## 拓展领域

价格对时间序号的斜率，量纲是「每个会话多少价格单位」。79 个会话序号的平方和 Σt² 已经很大，两位数的 λ 加进左上角，曲率几乎还在原地。这就是 50 在这段序号上做不成惩罚的原因：它没有大到能跟 Σt² 讨价还价。20000 大到足以把斜率从 0.0299 收到 0.0201，少倾斜 0.0098。换一段更短的序号，同一个 20000 会压得更狠。λ 没有脱离横轴尺度的标准值。

只惩罚斜率、放过截距，适合「水平可以任意，倾斜要付出代价」的设定。复权价的整体高低仍由数据决定。若把 λ 加到单位阵的两个对角元上，截距也会被拉向 0，拟合出来的是另一条线。那不是这个脚本。这个脚本的 Gram 矩阵只在斜率格上加 20000。

收缩也不是删点。第 41 天拿掉 2024-02-28，斜率仍是 0.029901。今天一个点不删，靠惩罚把斜率收到 0.0201。两天回答两件事：单个跳空在长样本上几乎不改斜率；显式的斜率惩罚改得动斜率，前提是 λ 相对 Σt² 足够大。

惩罚改的是斜率，截距跟着这条新斜率重新配合，脚本却不打印截距。因此今天交得出的是 0.0299 和 0.0201，交不出一条带截距的岭回归方程。少掉的 0.0098 先记在斜率上。水平要等两条线离开交点才分开，那是第 49 天的读数：跳空下标上直线和岭回归都是 11.0315，十日之后才是 11.3305 和 11.2326。今天把惩罚的位置固定在斜率格，λ 固定为 20000。
