# 第 51 天 · 五日收益的线性权重

[第一阶段 · 模型](README.md) · 可运行

今天的学习要点：在 AAA 上，用 lag1–lag5 简单收益预测当日简单收益。OLS 得 lag1=−0.1359，lag2=0.0829，lag3=0.1094，lag4=−0.1726，lag5=−0.0803，截距=0.0023。min=−0.1726，max=0.1094，test MSE=0.000081。五系数同量级，非等权。

## 费曼法讲解

第 50 天还在价格水平上做方向投票；从今天起特征链改成「过去五日简单收益 → 当日简单收益」。把一行想成卡片：左五格是 lag1 到 lag5，右格是当日要解释的收益。训练段取时间顺序前百分之七十五，在这叠卡片上找五个权重加一个截距，使训练平方误差尽量小。

五个权重不是「各 0.2」。lag4=−0.1726 绝对值最大；lag3=0.1094 是最大正数；lag1=−0.1359 也是显著负权重。lag2=0.0829、lag5=−0.0803 较小，但仍与 lag1、lag3 同量级。截距 0.0023 是整堆卡片上的常数项，不是第六个 lag。

测试 MSE 0.000081 只在后十九行上计算：用训练段 frozen 的六个数去预测，再与标签比平方后平均。min 与 max 相差约 0.28，等权假设不成立。权重正负交替，说明直线在做加权求和，而不是只盯 lag1。

手算核对时，请把 lag4 与 lag3 放在同一张小表里：一个拉低预测、一个抬高，合起来不是「最近一天说了算」。若你逐行算 (y−ŷ)² 再平均，得到 0.000081 才与脚本一致；用训练段重估系数再去测十九行，数字会漂，那是切分纪律错误。

数据来自 days/data/panel.csv 的 AAA 行：简单收益由复权收盘相邻两日比值减一。有效样本从第五个收益之后才开始，因此比原始行数少五行。默认切分是这些有效行按日期排序后的前百分之七十五训练、其余测试（本段多数课为 train=54、test=19）。同一交易日的 high、low、close 不能解释当日收益；同日 market 收益也不能当作合法标签或特征，除非当天脚本明确允许。

## 拓展领域

矩阵写法：设计矩阵每行是 [lag1,…,lag5,1]，响应是当日收益。正规方程在训练行上求 β̂；测试行只代入 ŷ=Xβ̂。这与第 9 天行序不变性兼容：打乱训练行顺序不改变 OLS 解，但打乱时间会破坏 lag 特征构造——本课 lag 已按日历对齐，不要 shuffle。

第 52 天会在同一表上放一棵树桩；0.000081 是直线在后段的标尺，不是方向命中率。研究日志里把 forbidden 规则、切分与 test MSE 同页保存；英文 stdout 是权威来源，中文是解释层，六位小数必须一致。

BBB 与其他 name 只在指定天出现；不要把 AAA 的 0.000081 自动搬到别的股票。

## 与前后课的关系

往回看，第 50 天还在三条价格水平拟合序列上比一步方向；今天第一次把设计矩阵写成五列滞后简单收益加截距，标签是当日简单收益。这是整个 lag-5 合同的原点：以后凡是出现 test MSE 0.000081，都是在这套系数与 nineteen 行 hold-out 上复算。向前看，第 52 天会在同一表上放单 lag 树桩；请先把五个权重记牢，尤其 lag4=−0.1726 与 lag3=0.1094 的对抗关系。写笔记时画一条时间轴：左端是价格课，右端是 return 课，第 51 天是交界点。任何把 3.2700 斜率或 96.339 RSS 写进本页的人，需要回到第 1–10 天复习标签定义。团队分工建议：一人跑脚本抄 stdout，一人用表格解释权重符号，第三人只负责核对 train fifty-four 与 test nineteen 是否出现在打印里（本脚本隐式使用默认切分，但第 56 天会显式打印行数）。

给工程师的阅读顺序：先跑本日脚本对照 stdout，再读正文；不要跳过第 51 天直接读诊断课，否则不知道直线系数从哪来。写单元测试时，对 frozen 系数在 hold-out 上断言 MSE 或账单与打印一致；失败常见原因是混用 train 行或把 BBB 行掺进 AAA。文档截图应至少露出核心块英文键名与六位小数，便于他人 diff。复现环境建议 python3 与仓库 pinned numpy；末位浮点差不改变本课结论，但不应改合同整数如 quiet=10、jump=5、direction wrong=3。
