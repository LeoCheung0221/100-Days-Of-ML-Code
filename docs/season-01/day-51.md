# 第 51 天 · 五日收益的线性权重

[第一阶段 · 模型](README.md) · 可运行

今天的学习要点：在 AAA 上，用 lag1–lag5 简单收益预测当日简单收益。OLS 得 lag1=−0.1359，lag2=0.0829，lag3=0.1094，lag4=−0.1726，lag5=−0.0803，截距=0.0023。min=−0.1726，max=0.1094，test MSE=0.000081。五系数同量级，非等权。

## 费曼法讲解

把一行画成卡片：左五格是 lag1 到 lag5 的简单收益，右格是当日要解释的简单收益。训练段取时间顺序前百分之七十五。直线在这叠卡片上找五个权重加一个截距，使训练平方误差尽量小。

五个权重不是「各 0.2」。lag4=−0.1726 绝对值最大；lag3=0.1094 是最大正数；lag1=−0.1359。lag2=0.0829、lag5=−0.0803 较小，但仍与 lag1、lag3 同量级。截距 0.0023 是整堆卡片上的常数项，不是第六个 lag。

测试 MSE 0.000081 只在后十九行上计算：用训练段 frozen 的六个数去预测，再与标签比平方。min 与 max 相差约 0.28，等权假设不成立。权重正负交替，说明直线在做加权求和，而不是只盯 lag1。

不要把第 46 天价格 SSE 或第 42 天全样本斜率写进本表。特征链已从「时间对收盘」改为「五滞后对当日收益」。

复盘权重时，请把 lag4=−0.1726 与 lag3=0.1094 放在同一张小表里对照：一个拉低预测、一个抬高，合起来不是「最近一天说了算」。截距 0.0023 只在训练段估计，测试段十九行共用同一截距与五权重。若你手算 MSE，应用 frozen 系数逐行算 (y−ŷ)² 再平均，得到 0.000081 才与脚本一致。

## 核心知识

面板文件是 days/data/panel.csv，名称列 AAA，收益由复权收盘相邻两日比值减一得到。特征行从第五个收益之后才开始，因此有效样本比原始行数少五。除非当天脚本改写切分，训练集是这些有效行按日期排序后的前百分之七十五；剩余行只做测试，不参与重估系数或阈值。同一交易日上的 high、low、close 不能作为解释当日收益的输入；同日 market 收益也不能当作合法结果。

```text
weight lag 1 = -0.1359
weight lag 2 = 0.0829
weight lag 3 = 0.1094
weight lag 4 = -0.1726
weight lag 5 = -0.0803
intercept = 0.0023
weight min = -0.1726  weight max = 0.1094
test MSE = 0.000081
```

MSE 在 hold-out 行上是预测减标签的平方的平均，脚本用六位小数打印。return 上的 MSE 与早期「时间对价格水平」的 SSE 不是一列数；读第 51 天及以后的表时，不要把第 45、46 天的树 SSE 贴进来。

记录权重时建议按 lag 序号排表，并单独一行写 intercept=0.0023。报告 test MSE 时注明 hold-out 行数为十九，与 train fifty-four 成对出现。不要把 weight max=0.1094 误写成 lag4 的绝对值；lag4 的 −0.1726 才是 |w| 最大。

量化课程从价格水平转向 return 后，MSE 均在收益标签上计算。hold-out 行是唯一评分集合；训练行只用于参数估计。写实验记录时，把 forbidden 规则、切分方式与 test MSE 同页保存。英文 stdout 是权威来源，中文正文是解释层，两者数字必须一致。若本地复跑六位小数不一致，先核对 panel 路径、name 列与切分行数，再改笔记。

## 拓展领域

等权滞后组合是常见对照，但对照必须落在同一张表上。这里每个系数绝对值约在 0.08–0.17，说明每个 lag 都进入方程。读权重时不要写成因果份额；换切分、换股票或加 volume 会得到另一向量。

下一课在同一表上只放一棵树桩。0.000081 是直线在后段的标尺，留给树与岭回归。不要把 0.000081 读成方向命中率；本日只印 return MSE。

写笔记时，英文 stdout 键名与数值应原样抄写，不要把 line 与 tree 的 MSE 列对调。比较模型时，先确认标签列、特征列与切分行数一致，再读 improvement 或失手句。若脚本声明 FORBIDDEN 或 not a result，该列分数不进入结果表，即使六位小数更小。阶段一固定在 panel.csv 的 AAA 行上；BBB 只在指定天出现，不能把 AAA 的 0.000081 自动搬到 BBB。十行清单与单日脚本的关系是汇总与分项：汇总不替代分项复跑，分项也不省略汇总中的禁止项。
