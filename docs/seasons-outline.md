# 四季实战大纲

第 1 季的逐日目录在 [season-01](season-01/README.md)。本页是后面三季的审阅稿。

供审。第 1 季是正在写的 100 天：模型在历史收盘价上会不会说谎。后面三季各 100 天，仍然每天只比昨天难在一个地方。执行季停在纸面账本。

来源：100 Days of Quant ML 第 1 季目录，以及 LAT 路线图里的因子研究、选股、费用与涨跌停、纸交易。A 股日频。

| | |
|---|---|
| 季数 | 4 季，每季 100 天 |
| 已可跑 | 第 1 季的第 1 天 |
| 执行季的终点 | 纸面账本 |
| 对外发布 | 写完一天再标可跑 |

因子要算截面、公告日和 Rank IC。组合要算股票池、权重和换手。约束要算买不进和卖不出。执行要算信号日和成交日的账。密度跟第 1 季一样的话，这是三季。压成两季，后半段会变成名词表。

## 四季

| 季 | 回答的问题 | 第一百天能讲的一句 | 别人愿意自己跑的那个数 |
|---|---|---|---|
| 1 · 模型 | 这条线、这棵树的成绩有没有在说谎 | 数据到哪一天、什么不许用、哪三类错、为什么不下单 | 第四天收在 20，直线失手 8.2 |
| 2 · 因子 | 这个数对下一期收益有没有稳定的截面关系 | 哪个因子过线，哪个因为偷看或太像别人被淘汰 | 用报告期代替公告日，IC 变好，这次变好标成无效 |
| 3 · 组合与约束 | 扣掉买不进、卖不出和费用之后，还赢不赢基准 | 宇宙、得分、权重、约束、扣费后的超额 | 涨停过滤之后，超额掉下去的那一截 |
| 4 · 执行 | 名单变成持仓时，价格和数量差了多少 | 信号价和假设成交价的差，以及为什么停在纸面 | 用信号日收盘价成交的成绩，被标成无效 |

四张目录同时铺开，仓库会回到大纲。吸引人的是某一天的输出能复现：公告日让 IC 掉下来，涨停过滤让超额掉下来，信号日收盘价成交被标成无效。

写法与第 1 季相同。第 2 季在第 1 季的时间切分和泄漏讲完之后再开。实盘接口、券商和税务不放进可复现的仓库。

## 第 2 季 · 因子

### 要掌握的技术

| 知识点 | 要会算的东西 | 容易说谎的地方 |
|---|---|---|
| 截面 | 同一天每只股票一个因子值，对的是未来收益 | 拿股票自己的昨天当答案 |
| 因子定义 | 公式、回看窗口、字段，写进代码再算 | 先看结果再改窗口 |
| 去极值 | MAD 截尾。分位数截尾只作对照 | 极值被当成 alpha |
| 行业中性 | 对行业哑变量回归，取残差 | 收益其实来自押中某个行业 |
| 市值中性 | 对对数流通市值回归，取残差 | 收益其实来自小盘 |
| 标准化 | 当天股票池里做 z-score | 用全历史的均值，等于看见未来 |
| Rank IC | 因子排名与未来收益排名的 Spearman | 只报一个月特别高的 IC |
| ICIR | IC 均值除以 IC 标准差 | 均值好看、波动极大 |
| 方向比例 | IC 为正的期数占比 | 平均为正，但多数月份为负 |
| 十分位 | 十分组收益是否单调，头尾差 | 只展示头尾，中间是乱的 |
| 衰减 | 1、5、10、20、60 日 IC | 用一个持有期把衰减藏起来 |
| 因子相关 | 因子之间的 Spearman | 两个几乎相同的因子被说成分散 |
| 样本外 | 前一段估计，后一段再算 IC | 全样本 IC 当结论 |
| 动量 12-1 | 过去 12 个月收益，去掉最近 1 个月 | 把最近一个月的反转算进动量 |
| 短期反转 | 近 20 日收益取负 | 和动量混成一个故事 |
| 低波动、换手 | 60 日波动取负，20 日换手取负 | 不说明是在小盘上才有效 |
| EP、BP、ROE、营收增速 | TTM 利润或净资产比市值，营收同比 | 用报告期，公告之前就用上了 |
| 公告日 | 生效条件是公告日不晚于当天 | 用报告期截止日 |
| 历史成分 | 信号日当天的指数成分 | 用今天的成分股回看当年 |
| 股票池 | 全市场、沪深 300、中证 500 分开报 IC | 把小票上的 IC 说成大盘也有 |

### 十段实战

每一段十天。段内仍然一天只多一条约束。及格线沿用 LAT 里的经验量级：未来 20 日 Rank IC 均值过 0.02 才谈得上，ICIR 过 0.3 才谈得上稳定。这是检验用的门槛，不是承诺能达到。

| 天 | 这一段在练 | 今天的学习要点 |
|---|---|---|
| 01–10 | 做出一张截面表：日期、股票、因子、未来收益 | 不能再拿单只股票的时间序列交差 |
| 11–20 | 去极值、行业、市值、标准化，每步印出 IC 的变化 | 不能跳过预处理还把 IC 当结果 |
| 21–30 | Rank IC、ICIR、IC 为正的比例，门槛写进程序 | 不能只交一个最好看的月份 |
| 31–40 | 十分位是否单调，头组减尾组 | 不能只展示两头 |
| 41–50 | 1 到 60 日的衰减，选出持有期 | 不能自定一个好看的持有期 |
| 51–60 | 一个技术因子走完全流程，换时间段再走一遍 | 不能只在选中的那几年报成绩 |
| 61–70 | 两个因子的相关，以及合成后 IC 增加了多少 | 不能把两个很像的因子说成两个 alpha |
| 71–80 | 财务因子。报告期对上公告日 | 用报告期做出的 IC 提升标成无效 |
| 81–90 | 改用信号日的历史成分 | 用今天的成分回看，IC 变好也标成无效 |
| 91–100 | 一张表留下过线、且彼此不太相像的因子 | 淘汰原因必须对应上面某一格 |

## 第 3 季 · 组合与约束

没有约束的权重不是能下的单。第 2 季留下的因子是输入。

### 组合

| 知识点 | 要会算的东西 |
|---|---|
| 可投资宇宙 | 历史成分，去掉 ST、上市不足 6 个月、市值最末一成、成交额过低 |
| 合成 | 排名等权是基准。IC 加权、ICIR 加权只用过去的 IC |
| 选股 | 按得分取前 N 只。N 变了，超额要重算 |
| 权重 | 等权是基准。均值方差需要协方差，样本短会不稳 |
| 风险约束 | 单票上限、单行业上限、相对基准的行业偏离 |
| 调仓 | 新买、卖出、继续持有。换手是权重变化的绝对值 |
| 基准 | 相对沪深 300 或中证的超额，按月拆开 |

### 交易约束

| 知识点 | 要会算的东西 |
|---|---|
| 涨跌停 | 主板约 10%，创业板和科创板在 2020 年 8 月后约 20%，ST 约 5%。涨停往往买不进，跌停卖不出 |
| 停牌 | 连续停牌剔除。持仓中途停牌则卖不掉 |
| T+1 | 当天买入的数量当天不能卖 |
| 整手 | 100 股为一手，零股进不了买单 |
| 印花税 | 卖出。2023-08-28 之前按 0.1%，之后按 0.05% |
| 佣金与滑点 | 买卖都有佣金。成交额越大，滑点越贵 |
| 流动性 | 当日成交额不够时只成交一部分 |

### 十段实战

| 天 | 这一段在练 | 今天的学习要点 |
|---|---|---|
| 01–10 | 宇宙逐层剔除，每层印出剩下的股票数 | 不能用今天的全市场当当年的宇宙 |
| 11–20 | 等权合成对上最强的单因子 | 不能把合成说成必然更强 |
| 21–30 | IC 加权和 ICIR 加权 | 权重不许用全样本的 IC |
| 31–40 | 前 N 只。N 放大、缩小各算一次超额 | 不能只报一个最好看的 N |
| 41–50 | 等权，再加上单票和单行业约束 | 约束改掉了哪些名字，要列出来 |
| 51–60 | 买、卖、留，以及换手 | 不能忽略换手还谈超额 |
| 61–70 | 相对基准的超额，按月拆 | 有一个月独撑则删掉再算 |
| 71–80 | 涨停买不进，跌停和停牌卖不出 | 过滤前后的超额都要印出 |
| 81–90 | T+1、整手、分段印花税、佣金 | 扣完还赢不赢基准 |
| 91–100 | 一页说明：宇宙、得分、权重、约束、扣费后超额 | 页上每个数都能在输出里找到 |

## 第 4 季 · 执行

这一季停在纸面。可复现的部分是账本：信号价、假设成交价、股数、现金。券商接口、实盘资金和税务不写进仓库。LAT 的纸交易和监控留到这季的后半，用同一份名单对账。

### 要掌握的技术

| 知识点 | 要会算的东西 | 容易说谎的地方 |
|---|---|---|
| 信号日与成交日 | 收盘后出名单，下一交易日才成交 | 用信号日收盘价成交 |
| 目标到订单 | 目标权重换成股数，再换成买和卖 | 权重本身被当成已经成交 |
| 账本 | 现金加持仓市值，每天轧平 | 账对不上仍报收益 |
| 部分成交 | 成交量上限之内才算成交，剩余留下 | 假设想买多少就买到多少 |
| 排队失败 | 涨停的买单、跌停的卖单留到下一天 | 当天失败的单被删掉，像没发生 |
| 滑点 | 成交价相对信号价的偏离 | 用中间价假装成交 |
| 费用进现金 | 佣金和印花税从现金扣 | 费用只写在文末，不进账 |
| 执行偏差 | 假设成交相对目标持仓少赚或多亏多少 | 把研究里的超额当成到手的超额 |
| 纸面日志 | 应成交、假设成交、差额，一天一行 | 只留最终净值 |
| 容量 | 假设成交量占该股当日成交量的比例 | 比例很高仍沿用原来的超额 |

### 十段实战

| 天 | 这一段在练 | 今天的学习要点 |
|---|---|---|
| 01–10 | 信号日和成交日错开 | 用信号日收盘价做出的成绩标成无效 |
| 11–20 | 权重换成股数，再换成买卖单 | 不能停在权重表 |
| 21–30 | 现金和持仓每天轧平 | 账不平的那一天不能报收益 |
| 31–40 | 按当日成交额的一个上限部分成交 | 剩余股数要留在账上 |
| 41–50 | 涨停买单、跌停卖单延到下一天 | 失败的单不能消失 |
| 51–60 | 成交价偏离信号价 | 偏离的分布要印出来 |
| 61–70 | 佣金和印花税进入现金 | 扣费前后净值并排 |
| 71–80 | 纸面日志：应成交、假设成交、差额 | 不能只留一条净值曲线 |
| 81–90 | 执行偏差吃掉多少超额 | 研究超额和到手超额分成两列 |
| 91–100 | 成交量占比过高就缩小单子再算 | 讲清为什么这一季停在纸面，不下实盘 |
